# PC 에 시뮬레이터 설치하기 (에듀이노 로봇팔 실습)

로봇 없이 **PC 에서 혼자 연습하는** 시뮬레이터입니다. 한 번 설치하면 바탕화면 아이콘으로 열리고,
**인터넷이 없어도** 초급(블록)·중급(파이썬)·고급(ROS 2) 실습이 모두 돌아갑니다.

- 필요한 것: 크롬 또는 엣지 (윈도우·맥 모두). 관리자 권한, 파이썬, 다른 프로그램 설치는 필요 없습니다.
- 처음 한 번만 인터넷으로 약 15MB 를 받아 PC 에 저장합니다 (3D 로봇 모델, 파이썬 실행기).
- 실제 로봇을 움직일 때는 이 앱이 아니라 **로봇 주소**(`http://로봇IP:8080/console`)를 엽니다
  ([`robot-console.md`](../robot-arm/robot-console.md)). 시뮬레이터에서 통과한 코드를 거기에 붙여 넣어 실행합니다.

## 0. 설치 없이 바로 — 시뮬레이터 프로그램 (보여 주기용)
인터넷도 설치도 없이, 파일 하나로 어느 PC 에서나 띄워 보여 줄 때 씁니다 (윈도우 10/11).
1. `PhysicalAI-Simulator.zip` 을 풀면 **`Physical AI 시뮬레이터.exe`** 와 `읽어보세요.txt` 가 나옵니다.
2. exe 를 더블클릭 → 엣지(또는 크롬) 앱 창으로 시뮬레이터가 열립니다. 시작 화면이 끝나면 **[연결하기]** 를 누릅니다.
   **로봇 연결** 창이 이 PC 의 Wi-Fi 에서 로봇을 저절로 찾아 **사용자 이름 · IP · 로봇 ID** 로 보여 줍니다. 내 로봇의 [연결] 을 누르면
   그 로봇으로 바로 실습하고, 로봇 없이 하려면 [시뮬레이션만] (또는 시작 화면의 **시뮬레이터로 시작**) 을 누릅니다.
   (로봇 쪽 준비 — USB 의 wifi.txt 에 와이파이·비밀번호·사용자 이름: [`usb-kit.md`](usb-kit.md))
   - 처음 실행할 때 "Windows의 PC 보호" 창이 나오면 **[추가 정보] → [실행]**. 회사 코드 서명 인증서가 없어서 나오는 안내입니다.
3. 끝낼 때는 시뮬레이터 창과 뒤의 **검은 창**을 닫습니다 (검은 창이 프로그램 본체입니다).
- 블록·파이썬·ROS 2·색 따라가기·myAGV, 윗줄 **[교육]** 탭의 로봇공학 · 피지컬 AI 주제 23개(물리엔진 포함)와 자료실 PDF 까지 모두 이 PC 안에서 돌아갑니다.
  저장한 자세·진행·미션은 다음 실행에도 남습니다. [교육] 탭 수업 안내는 [`robotics-course.md`](../course/robotics-course.md).
- 만드는 법(개발자): `sh desktop-go/build.sh` → `desktop-go/dist/PhysicalAI-Simulator.zip`. 콘솔을 고치면 다시 만들어 나눠 줍니다.

1. 크롬(또는 엣지)으로 **https://physical-ai-lab-lake.vercel.app/console** 을 엽니다.
2. 오른쪽 위에 **"시뮬레이션 · 오프라인 가능"** 이 나올 때까지 기다립니다 (보통 몇 초).
   이 글자가 나오면 필요한 파일이 PC 에 저장된 것입니다.
3. 화면 맨 위의 **[PC에 설치]** 버튼을 누르고, 뜨는 창에서 **[설치]** 를 누릅니다.
   - 버튼이 안 보이면: 주소창 오른쪽 끝의 **설치 아이콘(모니터 모양 ⊕)** 을 누릅니다.
   - 엣지: 주소창 오른쪽 **… → 앱 → 이 사이트를 앱으로 설치**.
4. 바탕화면(또는 시작 메뉴)에 에듀이노 로고의 **"에듀이노 로봇"** 아이콘이 생깁니다.

## 2. 쓰기
- 아이콘을 누르면 주소창 없는 별도 창으로 열립니다. 에듀이노 로고가 나온 뒤 **로봇 모델**을 고릅니다
  (지금은 myCobot 280 RDK X5. 한 번 고르면 기억합니다). 창 크기에 맞춰 한 화면에 모두 보입니다.
  - 맨 위: [모델] · **[실습 | 검수 시연]** · ① **단계**(초급·중급·고급) · ② **작업 환경**(AI 키트·로봇팔 단독) ·
    ③ **실습**(주제별 목록. [검수 시연]에서는 검수 1~7 번호)
  - 왼쪽 **제어 패널**: 로봇 상태 → 움직이기(조그, 누르고 있으면 계속 움직임) → 자세(내 자세 저장·가기) → 도구(도구 없음 포함) → 작업대
  - 가운데: 실습 제목, 큰 3D 화면(맞춤·시점·**표시**(좌표축·관절축 등)·고화질·카메라),
    **실행 막대** [① 시뮬레이션 → ② 목표 → ③ 로봇용 코드 · 정지], 한 줄 기록
  - 오른쪽: 단계별 편집기 (블록 코딩 / 파이썬 / ROS 2 노드). 접으면 3D 화면이 넓어집니다
  - 자세한 설명은 [`robot-console.md`](../robot-arm/robot-console.md) 6절.
  - 창이 아주 좁으면(가로 1100px 미만) 위아래로 스크롤하는 화면이 됩니다.
- 검수 항목의 진행(✓)은 이 PC 의 앱에 저장되어, 다음에 열어도 남아 있습니다.
- 설치한 앱은 켤 때 파이썬도 미리 준비해 두어, 중급·고급 단계가 바로 실행됩니다.
- 인터넷이 없어도 됩니다. 인터넷이 있으면 켤 때마다 새 버전을 확인해 저절로 바꿉니다.

## 3. 로봇에 연결하기
- 오른쪽 위 파란 **[로봇 연결]** → 내 로봇의 **ID**(로봇 주소의 마지막 숫자, 예: 252)를 넣고 **[연결]**.
  그 로봇의 콘솔로 바뀌고 오른쪽 위에 "로봇 252 연결됨" 이 나옵니다. 자세한 것은 [`robot-console.md`](../robot-arm/robot-console.md) 5절.
- `robot_console.zip` 은 로봇에 푸는 파일입니다. PC 에서 풀 필요는 없습니다.

## 4. 결과를 실제 로봇으로
1. 시뮬레이터에서 [▶ 시뮬레이션] 을 통과시킵니다.
2. 중급·고급: 편집기의 코드를 복사합니다 (또는 [로봇용 파일로 받기]).
   초급: 3D 아래 [③ 로봇용 코드] → 나오는 파이썬 코드를 복사합니다.
3. 로봇 콘솔(`http://로봇IP:8080/console`)의 같은 단계·실습에 붙여 넣고,
   거기서 [▶ 시뮬레이션] → [▶ 로봇에서 실행] 합니다.

## 5. 문제가 생기면
| 증상 | 해결 |
| --- | --- |
| [PC에 설치] 버튼과 주소창 설치 아이콘이 모두 없음 | 시크릿 창이 아닌 보통 창인지 확인. 이미 설치되어 있으면 나오지 않습니다 |
| "오프라인 가능" 이 안 나옴 | 인터넷 연결을 확인하고 새로고침. 학교 보안 프로그램이 저장을 막는 경우도 있습니다 |
| 오래된 화면이 계속 나옴 | 인터넷에 연결한 채 앱을 한 번 닫았다 다시 엽니다 |
| 지우고 싶음 | 앱 창 오른쪽 위 **… → 제거** (크롬), 또는 윈도우 설정 → 앱에서 "에듀이노 로봇팔 실습" 제거 |
