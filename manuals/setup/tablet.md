# 태블릿으로 쓰기 (갤럭시 탭 · 아이패드)

로봇 학습 시뮬레이터는 태블릿에서도 그대로 열려요.
레인보우로보틱스 RB 처럼 **태블릿을 티칭 펜던트처럼 들고** 로봇을 조작하고 수업할 수 있어요.
따로 설치할 앱은 없어요. 태블릿의 인터넷 브라우저로 주소만 열면 돼요.

## 1. 준비물

| 항목 | 권장 |
| --- | --- |
| 태블릿 | 10인치 이상. 갤럭시 탭(안드로이드, **크롬**) 권장, 아이패드(**사파리**)도 돼요 |
| 방향 | **가로**로 들고 써요 (설정에서 화면 회전을 가로로 고정하면 편해요) |
| 네트워크 | 로봇 또는 선생님 PC 와 **같은 Wi-Fi** |

> 참고: 태블릿은 프로그램을 받아 오는 화면일 뿐이에요. 로봇(또는 선생님 PC)이 켜져 있어야 열려요.

## 2. 주소 열기

두 가지 중 하나로 열어요.

::: step 로봇과 함께 (실제 로봇 조작)
1. 태블릿을 로봇과 같은 Wi-Fi 에 연결해요.
2. 크롬(또는 사파리) 주소창에 `http://로봇IP:8080/console` 을 넣어요.
   로봇 IP 는 로봇 화면이나 PC 프로그램의 [로봇 찾기]에 나와요 (예: `http://192.168.0.21:8080/console`).
3. 로봇 한 대는 한 화면만 움직여요. 다른 PC · 태블릿이 움직이는 중이면 화면에 알림이 뜨고, 그동안 명령은 받지 않아요 (멈추기는 언제나 돼요).
:::

::: step 로봇 없이 (시뮬레이터)
1. 태블릿 크롬(또는 사파리)으로 시뮬레이터 웹 주소를 열어요.
2. 진도와 결과는 그 태블릿의 브라우저에 남아요.
:::

## 3. 앱처럼 쓰기

::: step 홈 화면에 추가
- 갤럭시 탭 · 크롬: 오른쪽 위 [⋮] → [홈 화면에 추가]
- 아이패드 · 사파리: [공유] → [홈 화면에 추가]

바탕화면 아이콘으로 바로 열 수 있어요.
:::

::: step 전체 화면
화면 오른쪽 위 [⤢ 전체 화면] 버튼을 누르면 주소창이 사라져 화면을 넓게 써요.
다시 누르면 돌아와요.
:::

> 팁: 수업 중에 화면이 꺼지지 않게 태블릿 [설정] → [디스플레이] → [화면 자동 꺼짐 시간]을 10분 이상으로 바꿔 두세요.

## 4. 손가락으로 조작하기

| 하고 싶은 것 | 손가락으로 |
| --- | --- |
| 버튼이 무엇인지 보기 | 버튼을 **0.5초 길게** 누르면 설명이 떠요 (버튼은 눌리지 않아요) |
| 관절 · 좌표 조그 | 화살표 키를 **누르고 있는 동안** 움직여요. 손을 떼면 멈춰요 |
| 3D 돌려 보기 | 한 손가락으로 끌기 |
| 3D 확대 · 이동 | 두 손가락으로 벌리기 · 오므리기 · 끌기 (오른쪽 [+][−] 버튼도 돼요) |
| 3D 관절 다이얼 | 관절 점을 누르면 고리가 나와요. 고리를 손가락으로 돌려요 |
| 블록 넣기 | 블록 꾸러미에서 **누르면** 들어가요 (끌지 않아도 돼요) |
| 반복 안에 넣기 | 반복 블록의 [＋ 반복 안에 넣을 블록 고르기]를 누른 뒤, 꾸러미의 블록을 눌러요 |
| 블록 옮기기 | 블록을 눌러 고른 뒤 [↑][↓]. 반복의 위아래 끝에서 누르면 반복 밖으로 나가거나 안으로 들어가요 |
| 정지 | 오른쪽 아래 [■ 정지], 실제 로봇은 위쪽 빨간 [로봇 정지] |

> 안전: 실제 로봇을 움직일 때는 태블릿을 든 사람이 항상 [로봇 정지]에 손이 닿게 해요. 태블릿은 키보드 Esc 가 없어요.

## 5. 태블릿에서 다른 점

- **화질**: 태블릿은 3D 를 [보통] 화질로 그려요 (태블릿에서도 부드럽게 돌도록).
- **Python · ROS 2**: 화면 키보드로 코드를 치기는 불편해요. 태블릿 수업은 **블록 코딩**을 권해요.
- **파일 받기**: 결과 파일 · 기록지는 태블릿의 [내 파일](아이패드는 [파일]) 앱 [다운로드]에 저장돼요.
- **PC 전용 기능**: Windows 프로그램 받기, 로봇 USB 만들기는 PC 에서 해요.
- **오프라인**: 태블릿만으로는 열리지 않아요. 로봇이나 선생님 PC 가 같은 Wi-Fi 에 켜져 있어야 해요.

## 6. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 주소가 안 열려요 | 같은 Wi-Fi 인지, 주소 앞이 `http://` 인지(`https` 아님), 포트(`:8080` · `:47290`)가 맞는지 확인해요 |
| 화면을 아래로 끌면 새로고침돼요 | 최신 버전에서는 막혀 있어요. 크롬을 업데이트해 주세요 |
| 3D 가 끊겨요 | 다른 앱을 닫아요. 교육 현장 화면은 3D 오른쪽 [현장 주변 보기]를 꺼요 |
| 글자가 작아요 | 두 손가락으로 화면을 벌려 확대할 수 있어요. 크롬 [설정] → [접근성] → 글자 크기도 돼요 |
| [데스크톱 사이트] 로 열려요 | 크롬 [⋮] → [데스크톱 사이트] 체크를 끄세요 |
