# 실기 점검 실행 방법

대상 파일: `robot-python/checks/robot_check.py` — myCobot 280 RDK X5 **로봇 안에서** 실행합니다.

로봇에 수업 콘솔을 설치하는 데 필요한 환경(OS·저장공간·IP·열린 포트·실행 중인 공식 프로그램)을
조사하고, 연결, 각도 읽기 속도, 작은 동작, 정지, 손으로 움직이기(서보 풀기), 그리퍼,
좌표계(로봇이 계산하는 좌표의 기준 높이)를 차례로 확인하고 결과를 복사할 수 있게 한 번에
보여 줍니다. 이 결과로 실제 연동 방식과 시뮬레이터의 높이 기준을 정합니다.

## 1. 로봇으로 파일 옮기기 (셋 중 편한 방법)
- **로봇 화면에서:** 브라우저로 GitHub 에 로그인 → `robot-python/checks/robot_check.py` → Raw → 저장
- **PC 에서:** 파일을 받아 복사
  `scp robot_check.py <로봇 계정>@<로봇 IP>:~/`
- **USB 메모리**로 옮기기

## 2. 실행 전 확인
- 로봇 전원을 켜고, 팔 주변 30cm 안에 물건과 손이 없게 합니다.
- 로봇에서 공식 앱이나 ROS 예제가 켜져 있으면 끕니다. (같은 포트를 쓰면 결과가 틀어집니다.
  스크립트가 포트를 쓰는 다른 프로그램을 찾아서 알려 줍니다.)

## 3. 실행 (로봇의 터미널에서)
```bash
python3 robot_check.py
```
- 포트 권한 오류가 나면 `sudo python3 robot_check.py`
- `pymycobot` 이 없다고 나오면 `pip3 install -U pymycobot` 후 다시 실행
- 움직이는 단계마다 먼저 물어봅니다. **Enter = 진행, s = 건너뛰기**
- **언제든 Ctrl+C 를 누르면 로봇이 멈추고** 그때까지의 결과를 보여 줍니다.
- "손으로 움직이기" 단계에서는 서보가 풀려 팔이 떨어질 수 있으니
  **반드시 한 손으로 팔을 받친 채** 진행합니다.

## 4. 결과 보내기
마지막에 나오는 `[myCobot 280 RDK X5 실기 점검 결과]` 블록을 그대로 복사해서 보내 주세요.
홈 폴더에 `mycobot_check_날짜_시간.txt` 로도 저장됩니다.

## 5. AI 로봇 확장 키트 — 자로 재서 함께 보내 주세요
시뮬레이터의 키트는 Elephant Robotics 공식 3D 모델과 공식 키트 코드·사진으로 맞췄습니다.
아래 값만 공식 자료로 확정하지 못했습니다. 실물에서 재면 그대로 반영합니다.

| 잴 것 | 방법 | 지금 시뮬레이터 값 |
| --- | --- | --- |
| 카메라 렌즈 높이 | 흰 보정판 윗면에서 렌즈까지 (수직) | 368mm (공식 2023 키트 모델) |
| 카메라 위치 | 렌즈 바로 아래 판 위의 점 — 로봇 중심에서 앞쪽(x)·왼쪽(y) 거리 | x 165.5, y 0.4mm (공식 2023 키트 모델) |
| 흰 보정판 중심 | 로봇 중심에서 앞쪽·왼쪽 거리 | x 160.3, y 0.4mm (공식 2023 키트 모델) |
| 블록 한 변 | 자로 | 25mm (공식 코드에서 계산) |
| 마커 | 보정판의 검은 사각 마커 한 변, 인쇄된 번호(있다면) | 21mm, id 1·2 |
| 로봇 고정 방식 | 로봇 바닥이 받침판에 바로 닿는지, 받침대 위에 있는지 (높이) | 받침판 위에 바로 |
| 흡착 펌프 연결 | 펌프 선이 베이스 40핀의 어느 핀에 꽂혔는지 | 31·37번 (RDK X5 공식 비전 키트) |

카메라 화면 사진 1장(콘솔의 [실제 카메라] → [사진 찍기])도 함께 보내 주시면 시야각을 바로 맞출 수 있습니다.
지금 시야각은 제품 사양(110°)에서 계산한 값이라 실물 사진으로 확인이 필요합니다.

## 참고
