# 이동 로봇(myAGV) 주행 실습 켜기

대상 폴더: `robot-python/server/` — 로봇팔과 같은 폴더·같은 화면 파일을 쓰고, 서버만 `agv_server.py` 입니다.
서버는 **myAGV 안(라즈베리 파이 / 젯슨 나노)** 에서 켜고, 화면은 **PC 브라우저**에서 엽니다.

할 수 있는 것
- **조이스틱**(끌기) · **키보드**(W A S D 이동, Q E 돌기, Space 멈춤) · **게임패드**(왼쪽 스틱 이동, 오른쪽 스틱 돌기, B 멈춤)로 주행
  - 메카넘 바퀴라 **옆으로도** 갑니다 (조이스틱을 좌우로, 또는 A D)
  - 손을 떼면 멈춥니다. 화면이 멈추거나 Wi-Fi 가 끊겨도 **0.5초 안에 로봇이 스스로 멈춥니다**
- **앞 카메라**: 실제 로봇 카메라 영상, 또는 시뮬레이션 카메라(카드·마커를 찾아 이름·거리·위치 표시)
- **라이다**(시뮬레이션): 주변 물체까지 거리, 빨간 점으로 보기
- **직진 보정**: 1m 직진 테스트 → 휜 만큼 보정값 저장 → 다시 테스트로 확인 (값은 로봇에 저장되어 다음에도 쓰임)
- **불빛**: 로봇 뒤쪽 LED 색 바꾸기
- 로봇 없이도 PC 에서 같은 화면으로 연습(시뮬레이션). 모델은 **myAGV 2023 Pi / 2023 Jetson Nano / Plus** 중 선택

> 이 판의 실제 로봇 제어는 **myAGV 2023(라즈베리 파이 · 젯슨 나노)** 기준입니다 (pymycobot `MyAgv`).
> myAGV Plus 는 3D 모델·시뮬레이션만 되고, 실제 제어는 다음 판입니다.

> **가장 쉬운 방법: USB 키트** — [`usb-kit.md`](../setup/usb-kit.md). 로봇팔과 같은 USB 로, 명령 한 줄이면 1·3·4절이 한 번에 끝나고
> (라즈베리 파이 보드면 로봇 종류를 물을 때 Enter = myAGV), 그 뒤로는 `wifi.txt` 만 고쳐 꽂으면 됩니다.

## 1. 파일 준비와 풀기
로봇팔과 같은 `robot_console.zip` 을 씁니다 (로봇팔 매뉴얼 `robot-console.md` 1·2절과 같음).
myAGV 의 기본 사용자 폴더에 풉니다.
```bash
cd ~
rm -rf ~/robot_console
python3 -m zipfile -e /media/<USB 이름>/robot_console.zip ~/
cd ~/robot_console
```

## 2. 실행 전 확인
- 바닥에 두고, 주변 1m 를 비웁니다. 처음에는 **최고 속도 0.10~0.20 m/s** 로 시작합니다 (교실 최고 0.5 m/s 로 막혀 있음).
- 배터리를 충분히 충전합니다. 전원 스위치를 켜고 파이(젯슨)가 다 켜질 때까지 1분쯤 기다립니다.
- 공식 ROS 프로그램(`myagv_active.launch` 등)이 켜져 있으면 같은 포트를 쓰므로 먼저 끕니다.
- 파이썬 라이브러리 확인: `python3 -c "import pymycobot; print(pymycobot.__version__)"` (없으면 `pip3 install pymycobot`)

## 3. 서버 켜기
```bash
cd ~/robot_console
python3 agv_server.py              # 2023 Pi: 바닥 보드 /dev/ttyAMA2, 115200
python3 agv_server.py --demo       # 로봇 없이 가짜 로봇으로 (화면 연습용)
python3 agv_server.py --serial /dev/ttyTHS1    # 2023 Jetson Nano 는 포트를 지정 (보드에 따라 ttyTHS1 또는 ttyS0)
python3 agv_server.py --camera 0   # 카메라 번호 지정 (기본 auto: /dev/video0~9 중 영상이 나오는 것)
```
켜지면 `★ 로봇 ID: 105` 와 `브라우저 주소: http://…:8080/console` 이 나옵니다.
- "로봇 바닥 보드에 연결하지 못했어요" → 포트 이름(`ls /dev/ttyAMA* /dev/ttyTHS* /dev/ttyS*`), 다른 프로그램이 포트를 쓰는지 확인.
  포트 권한 문제면 `sudo usermod -aG dialout $USER` 후 다시 로그인.

**전원만 켜면 서버가 저절로 켜지게 (한 번만, 권장)**
```bash
sudo python3 autostart.py --agv
```
상태 보기·끄기는 로봇팔과 같습니다 (`python3 autostart.py --status`, `sudo python3 autostart.py --off`).

## 4. 교실 Wi-Fi 에 붙이기 (로봇마다 한 번)
USB 키트([`usb-kit.md`](../setup/usb-kit.md))를 쓰면 `wifi.txt` 를 고쳐 꽂기만 하면 됩니다. 직접 할 때:
로봇팔 매뉴얼 **4-2절**과 같습니다. 교실 공유기(예: `EDUINO-LAB`)에 한 번 붙여 두면, 다음부터 켜기만 하면 됩니다.
```bash
sudo python3 wifi.py EDUINO-LAB 비밀번호
```
또는 콘솔 오른쪽 위 연결 버튼 → **[로봇 Wi-Fi]** 탭.

## 5. PC 에서 접속
1. PC 를 로봇과 같은 Wi-Fi 에 연결하고 에듀이노 실습 앱(또는 사이트)을 엽니다.
2. 모델 고르기에서 **myAGV** → 이동 로봇 화면이 열립니다. (로봇팔 화면에서는 위쪽 [모델] 버튼)
3. 오른쪽 위 **[로봇 연결]** → **[로봇 찾기]** → 목록에서 myAGV 를 찾고 **[움직여 확인]**
   (그 로봇이 불빛을 깜빡이며 제자리에서 살짝 돌았다 돌아옵니다) → **[연결]**.
4. 오른쪽 위에 **"로봇 105 연결됨"**, 위쪽에 **REAL**(데모 서버면 DEMO)이 보이면 성공입니다.

## 6. 화면
- **왼쪽 주행 패널**
  - 로봇 상태: 연결·배터리·주행 중, 위치(X·Y m)·방향(°)·속도, 라이다 거리
    (실제 로봇일 때 화면 속 위치는 **보낸 명령으로 계산한 값**이라 실제와 조금 다를 수 있어요)
  - 조종: 조이스틱(이동), 돌기 막대, **[■ 멈춤]**, 최고 속도, 키보드·게임패드 표시, [출발 칸으로 옮기기](시뮬레이션)
  - 직진 보정 (7절), 불빛
- **가운데 3D**: 교실 바닥(로봇팔 화면과 같은 바닥·격자), 코스 매트, 보정 줄(노란 테이프), 상자, 색 카드·마커
  - 오른쪽 위 보기: [맞춤] [위] [뒤따라 보기], 표시: [궤적] [카메라 시야] [라이다]
- **앞 카메라**(오른쪽 아래): 실제 로봇이면 [로봇] 영상, [시뮬레이션] 으로 바꾸면 찾은 카드·마커에 이름·거리가 붙습니다.

## 7. 직진 보정 — 곧게 가지 않고 휠 때
바퀴 모터 4개의 힘이 조금씩 달라 "앞으로" 만 해도 한쪽으로 휩니다. myAGV 는 모터를 하나씩 따로 조정하는 명령이 없어서,
**1m 갈 때마다 조금 돌고 옆으로 미는 보정값**을 저장해 둡니다 (서버가 모든 주행에 더해 줌).

**실제 로봇**
1. 바닥에 **1m 테이프**를 곧게 붙이고, 로봇 가운데를 테이프 시작점에, 앞을 테이프 방향으로 맞춥니다.
2. **[▶ 1m 직진 테스트]** — 로봇이 0.2 m/s 로 5초 동안 스스로 갑니다. (중간에 멈추려면 [■ 멈춤])
3. 멈추면 **로봇 가운데가 테이프에서 옆으로 몇 cm 벗어났는지** 잽니다. 왼쪽이면 +, 오른쪽이면 − (예: 오른쪽 3.5cm → `-3.5`).
4. **[보정 저장]** → 로봇 제자리에 두고 다시 **[▶ 1m 직진 테스트]** 로 확인합니다. 1cm 안이면 끝.
   - 저장한 값은 로봇의 `~/.agv_console.json` 에 남아, 서버를 다시 켜도 쓰입니다. [보정 지우기] 로 없앨 수 있습니다.

**시뮬레이션** — 시뮬레이션 로봇은 일부러 뒤 오른쪽 모터를 12% 약하게 만들어 두었습니다.
1m 테스트를 하면 빨간 선처럼 휘고, 화면이 휜 정도(각도·cm)를 재 줍니다. [보정 저장] 후 다시 하면 초록 선으로 곧게 갑니다.
[방향 유지 (자이로)] 를 켜면 보정값 없이도 방향을 바로잡으며 갑니다 (자이로로 방향을 붙잡는 방식 비교용).

## 8. 막아 둔 것 (안전)
- 최고 속도 0.5 m/s, 회전 1.5 rad/s (서버에서도 한 번 더 제한)
- 화면에서 유지 신호가 0.5초 끊기면 로봇이 스스로 멈춤 (Wi-Fi 끊김·탭 닫힘·PC 멈춤 대비).
  유지 신호는 화면과 따로 보내서, 3D 가 잠깐(1초 안) 느려져도 주행이 끊기지 않습니다
- [■ 멈춤] · Space · Esc 는 언제나 바로 멈춤
- 시뮬레이션에서는 벽·상자·받침대에 부딪히기 전에 멈춤 (실제 로봇은 멈추지 않으니 주변을 비워 두기)

## 9. 확인이 필요한 것 (실물에서)
- 배터리 전압 읽기: 공식 문서의 상태 값 순서를 따랐으며, 실물에서 값이 맞는지 확인 필요
- 젯슨 나노판의 바닥 보드 포트 이름 (`--serial`)
- 속도 값과 실제 m/s 의 관계 (명령 = 속도×100 + 128, 공식 ROS 드라이버 기준)
