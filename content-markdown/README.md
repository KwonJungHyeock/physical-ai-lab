# 교육 콘텐츠 원고 (로봇공학 8개 학문)

이 폴더의 `N-학문명.md` 파일이 교육 탭의 내용 **원본**입니다. 앱은 이 파일을 그대로 읽어
주제 화면, 자료실 PDF(실습교육서), 용어 사전을 만듭니다. 내용을 고칠 때는 이 파일만 고치면 됩니다.

**주제 하나 = 1 차시(50분)** 이고, 화면과 교재는 수업 순서대로 갑니다:
도입(학습 목표 · 생각 열기 · 그림 · 핵심 정의, 5분) → 개념(원리 · 자세히 · 대학 수식 · 기호 표, 10분) →
탐구 활동 1 · 2 · 3(활동 목표 · 예상해 보기 · 할 일 · 볼 것 · 기록 · 시연 · 왜 그럴까, 20분) →
정리(세 활동 비교 · 기억할 것 · 현장에서는 · 학습 목표 확인, 10분) → 평가(확인 문제 · 다음 차시, 5분).
28주제가 1~28차시입니다.

| 파일 | 학문 | 주제 |
| --- | --- | --- |
| `1-기초로봇공학.md` | 1 기초 로봇공학 | 1-1 ~ 1-4 |
| `2-기구학역기구학.md` | 2 기구학 & 역기구학 | 2-1 ~ 2-3 |
| `3-미분기구학궤적.md` | 3 미분기구학 · 궤적 생성 | 3-1 ~ 3-4 |
| `4-로봇동역학.md` | 4 로봇 동역학 | 4-1 ~ 4-3 |

학문 1 은 콘텐츠 담당자 샘플, 2~8 은 그 형식에 맞춘 **초안**입니다(검토 후 확정).
`reference/roadmap-v3.txt` 는 로드맵 v3 PDF 의 글자만 뽑은 참고본입니다.

## 형식 (줄 모양을 바꾸지 마세요)

샘플 `1-기초로봇공학.md` 와 똑같이 씁니다. 앱이 줄 모양으로 읽기 때문에, 형식이 틀리면
고친 곳의 **파일 이름과 줄 번호**를 알려 주며 멈춥니다.

- `# N 학문명` 아래 `- 영문:` `- 이 학문을 마치면(한 줄):` `- 선수 학문:` (없으면 `없음`, 여러 개면 `1 기초 로봇공학, 2 …`)
- 주제마다 `## N-M 제목` 아래
  `- 영문:` `- 질문:`(도입의 생각 열기) `- 학습 목표:`(두 칸 들여 `  - ` 로 2~3 개, "~할 수 있다") `- 정의(한 줄):`
  `- 원리(2~3줄):`(아래에 두 칸 들여 `  - `) `- 자세히(2~4문단):`(아래에 두 칸 들여 쓰고, 문단 사이는 빈 줄)
  `- 수식(대학, 한 줄에 하나):`(두 칸 들여 `  - `) `- 용어:`(쉼표로) `- 기호:`(아래 참고) `- 그림: 설명  [N-M.png]`
  `- 기억할 것(한 줄):` `- 현장에서는:`(실제 로봇 현장에서 쓰이는 곳, 1~2 문장)
- `### 탐구 활동 (같은 동작을 한 가지만 바꿔 세 번)` 아래 활동 세 개를 차례로:
  ```
  - 활동 1 이름
    - 목표: 이 활동에서 알아볼 것 (한 줄)
    - 예상: 하기 전에 예상해 볼 질문 (답은 쓰지 않음)
    - 할 일: 화면에서 할 것 — 버튼 · 슬라이더 이름은 [이름]
    - 볼 것: 보이는 결과와 숫자
    - 왜: 해 본 뒤 읽는 설명 (2~3 문장)
  - 활동 2 …
  - 활동 3 …
  - 비교할 값: …
  - 비교(한 줄): …
  ```
  (`비교할 값` · `비교` 는 들여 쓰지 않습니다.) 활동은 쉬운 것 → 어려운 것, 바뀌는 것은 하나씩.
- `### 문항` 아래 주제마다 **OX 10 + 객관식 10**, 각각 기본 4 → 응용 4 → 대학 2 순서
  - `- OX | 기본 | 문항 | O | 해설: …`
  - `- 객관식 | 응용 | 문항 | ① … ② … ③ … ④ … | 정답 ② | 해설: …`
  - 문항·보기·해설 안에 ` | ` (띄어 쓴 세로줄)을 쓰지 마세요. 칸을 나누는 기호입니다.
  - OX 정답은 O·X 가 반반쯤, 객관식 정답 번호는 ①~④ 가 고르게.
- 파일 끝에 `## 새 용어` (`- 용어 | English | 뜻`) 와 `## 참고` (`- 문헌`).
  `용어:` 칸에 쓴 말이 용어 사전에 없으면 꼭 `새 용어` 에 넣어 주세요. 같은 뜻의 다른 이름
  (예: "공구 중심점(TCP)" / "도구 끝점", "회전행렬" / "회전 행렬")은 앱이 알아서 맞춥니다.
- 그 밖의 `## 제목` 칸(예: 메모)은 앱이 읽지 않습니다.

## 수업 카드 · 활동 카드 (수업 화면의 짧은 카드)

수업 화면은 단계마다 카드 한 장(핵심 한 줄 · 그림 · 선생님이 물어볼 것 · 학생이 할 것 · 정답)으로 보여 줍니다.
긴 글(자세히 · 왜)은 그대로 두고 "더 보기"와 PDF 에 쓰고, 카드에는 아래 짧은 줄을 씁니다. 예: `1-1`.

주제마다 `- 현장에서는:` 바로 아래:
```
- 수업 카드:
  - 도입 발문: 질문 1 / 질문 2          (선생님이 수업을 여는 질문, 1~2개, " / " 로 나눔)
  - 도입 할 일: 할 일 1 / 할 일 2       (질문이 열려 있는 동안 학생이 하는 것, 1~2개)
  - 개념 발문: 질문                    (정의를 확인하는 질문 하나)
  - 정리 발문: 질문                    (수업을 닫는 질문 하나)
  - 정리 답: 한두 문장                 (그 답)
```
활동마다 `- 왜:` 바로 아래(네 칸 들여):
```
    - 바꾸는 것: 이름 | 값       (활동 1 은 처음 값 "J1 하나", 활동 2·3 은 "앞 → 뒤" 예: "1개 → 2개 (J2·J3)")
    - 보기: 가 / 나 / 다 | 정답 2  (예상 질문의 보기 2~4개와 맞는 번호 — 시뮬레이터 결과(볼 것)와 같아야 함)
    - 핵심(한 줄): A → B          (활동 결과 한 줄, 30자 안쪽)
    - 왜(한 줄): 한 문장          (긴 "왜"를 한 문장으로)
    - 발문: 질문                  (활동 중 선생님이 묻는 말)
```
쉬운 말로, 짧게 씁니다(고등학생이 처음 읽어도 아는 말). 안에 ` | ` 와 ` / ` 는 나누는 기호로만 씁니다.

## 기호 (K, m, μ, Kp, θ₁ … 한 글자짜리 양)

대부분의 학생은 기호를 모릅니다. 그래서 주제마다 쓰는 기호를 `- 기호:` 칸에 풀어 두고, 본문에서는 백틱으로 표시합니다.

```
- 기호:
  - Kp | 케이 피 | 비례 게인 — 지금 오차에 곱하는 수. 클수록 세게, 빨리 고친다 | 없음
  - μ | 뮤 | 마찰 계수 — 미끄러지기 어려운 정도 | 없음
```

- 칸: `기호 | 읽는 법 | 짧은 이름 — 쉬운 풀이 | 단위(없으면 없음)`. 기호가 없는 주제는 `- 기호: 없음`.
- 본문·실습·문항에서 `` `Kp` `` 처럼 표시합니다. 앱과 PDF 는 표시한 기호를 교과서처럼 기울여 쓰고, **페이지에서 처음 나올 때 짧은
  이름을 기호 위에 작게** 붙이며(Kp 위에 "비례 게인"), 누르면 읽는 법·뜻·단위가 나옵니다. 주제마다 **기호 표**가 붙습니다.
- 표시하지 않는 것: 단위(mm, g, s, N·m), 관절 이름(J1~J6), 활동 번호(활동 1·2·3), 약어(TCP, RRT, HSV), 화면 이름 `[Kp]`, `- 수식:`·`- 그림:` 줄.
- `[실행]` 처럼 대괄호로 쓴 화면 이름은 앱에서 키 모양으로 보입니다.
- `npm run check:learn` 이 표시한 기호가 그 주제의 `기호:` 칸에 있는지 검사합니다.

## 그림 · GIF

`- 그림:` 의 설명은 그림 제작 지시입니다. 앱에는 이 설명과 그림 제작 요청서 규격으로 코드로 그린 그림
(`web-typescript/src/ui/education/fig/`, 1600×900, 칸 = 탐구 활동 ①②③)이 들어가고, 그림마다 번호·제목(캡션)과 기호 줄이 붙습니다.

- 그림 GIF: `node tools/build/figure-gifs.mjs` → `web-typescript/public/education/fig/N-M.gif` (그림 애니메이션, 수업 슬라이드용)
- 실습 시연 GIF: `npx tsx tools/check/learn-sim.mjs --clips` → `web-typescript/public/education/clips/N-M-A.gif` …(원고의 할 일대로 누른 화면)
- 앱의 실습 페이지 [▶ 시연 보기], 자료실 「그림 · 시연 GIF」 에서 보고 내려받습니다.

## 고친 뒤 (개발자)

```
cd web-typescript
npm run gen:curriculum   # md → src/engine/education/curriculum.gen.ts
npm run check:learn      # 형식·문항 수·수준·용어 검사
node tools/build/materials.mjs   # 자료실 PDF 다시 만들기 (개발 서버가 켜져 있어야 함)
```

탐구 활동의 할 일·볼 것은 시뮬레이터 화면(`web-typescript/src/ui/education/topics/`)과
맞아야 합니다. 버튼 이름이나 화면이 보여 주는 숫자를 바꾸면 화면도 함께 고쳐야 합니다.

**자동 대조**: `web-typescript/tests/education/sim/sN.ts` 에 실습마다 "누를 것"(할 일)과 "결과에 나와야 할 숫자"(볼 것)를 적어 두었습니다.
개발 서버를 켠 채 `npx tsx tools/check/learn-sim.mjs [주제 …]` 를 돌리면 브라우저가 원고대로 눌러 보고, 결과가 원고와 다르면
그 실습과 두 값을 알려 줍니다. 원고의 숫자를 고치면 여기도 함께 고칩니다.
