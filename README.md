2. 장비: 진동 피더(켜면 4 초마다 핀을 집는 자리로) · 하우징 컨베이어 · 스토퍼 · 클램프 지그 · 완성 상자.
   - 신호: 하우징 도착 · 클램프 닫힘 / 열림 · 핀 있음 · **걸림**(손목 힘 센서).
   - 블록 놓을 곳: 「구멍 1」 ~ 「구멍 4」, 「구멍 다음 칸」(비어 있는 다음 구멍).

   - 오차 = 속도 × 0.04 mm (속도 10 → 0.4 mm, 35 → 1.4 mm) + 클램프를 안 하면 2.5 mm.
4. 단계마다 조건이 하나씩 늘어요.
