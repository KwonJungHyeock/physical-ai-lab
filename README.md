## 새 로봇 준비 (로봇마다 처음 한 번, 모니터 · 키보드 없이)

1. 로봇 전원을 켜고 1분 기다려요.
2. **PC 랜 포트 ↔ 로봇 LAN 포트** 를 랜선 하나로 바로 이어요 (공유기 · 벽 랜선은 빼요. 랜 포트가 없는 노트북은 USB 랜 어댑터).
3. 프로그램 ⚙ 설정 → **[새 로봇 설치]** → 로봇이 붙을 Wi-Fi 이름 · 비밀번호 · 로봇 이름 → **[설치 시작]**.
   - "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 **[예]** (PC 랜 포트 주소를 설치하는 동안만 바꾸고 끝나면 되돌려요).
   - 공장 계정(sunrise / sunrise)으로 로봇에 들어가 설치하고 Wi-Fi 까지 맞춰요 (3~5분). 끝나면 로봇 ID · 주소와 **[이 로봇에 연결]**.
4. 안 되면: 로봇 키트 안 「처음 설치 (모니터로).txt」 순서대로 모니터 · 키보드로 (화면의 [그래도 안 되면] 에도 같은 순서).

그 뒤로 Wi-Fi 를 바꾸거나 로봇 프로그램을 업데이트할 때는 ⚙ → **[로봇 USB 만들기]** → USB 를 로봇에 꽂기.

## 지난 판 (10 월 27 일 · 5) — 핫스팟을 끈 뒤 Wi-Fi 장치가 "unavailable"

**로봇 USB 를 새로 만들어 꽂아 주세요** (이미 · 4 판을 설치한 로봇은 꽂기만 하면 저절로 업데이트돼요).

1. **핫스팟을 끈 뒤 Wi-Fi 장치(wlan0)가 "준비되지 않았어요 (unavailable)" 로 남던 것**: 무선 차단(rfkill) 풀기,
   wpa_supplicant 켜기, 핫스팟 주소(10.42.0.1) 지우기, 핫스팟 모드로 남은 칩을 일반 모드로 돌리기를 더 하고,
   그래도 안 되면 네트워크 관리자를 한 번 다시 켠 뒤 연결해요. 켤 때도 같은 순서로 Wi-Fi 장치를 먼저 살려요.
2. **랜선 직결 주소가 can0 에 붙던 것**: RDK X5 의 CAN 버스(can0)를 랜 포트로 잘못 골랐어요. 이제 이더넷 포트(eth0)에만 붙여요.
- 소스: `main` 커밋 e1b00cc, 로봇 키트 `20261027-042011-e1b00cc` (Ed25519 서명).
- 확인: USB 자체 시험 28/28, 가짜 nmcli 로 "unavailable → 네트워크 관리자 다시 켜기 → 연결 가능" 확인. 실제 로봇에서는 아직 확인 전이에요.
