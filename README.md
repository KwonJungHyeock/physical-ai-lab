# Physical AI 시뮬레이터 — 시험판

Windows PC 에서 바로 실행하는 시뮬레이터 프로그램입니다. 인터넷이나 로봇 없이 동작합니다.

## 받는 법

GitHub 는 100 MB 넘는 파일을 올릴 수 없어서, zip 하나(약 200 MB)를 세 조각으로 나눠 두었습니다.

1. 이 브랜치(`release`)에서 아래 네 파일을 **같은 폴더**에 받습니다. 파일을 누른 뒤 오른쪽 위 **Download** 를 누르면 됩니다.
   - `PhysicalAI-Simulator.zip.001` (90 MB)
   - `PhysicalAI-Simulator.zip.002` (90 MB)
   - `PhysicalAI-Simulator.zip.003` (12 MB)
   - `join.cmd`
2. 조각을 합칩니다. 둘 중 하나를 고릅니다.
   - **`join.cmd` 를 두 번 누르기** → 같은 폴더에 `PhysicalAI-Simulator.zip` 이 생깁니다. 그다음 Windows 기본 압축 풀기로 풉니다.
   - 또는 반디집 · 7-Zip 으로 `PhysicalAI-Simulator.zip.001` 을 열면 나머지 조각을 저절로 이어서 풉니다.
3. 풀면 `Physical AI 시뮬레이터` 폴더가 나옵니다. 그 안의 **`Physical AI 시뮬레이터.exe`** 를 두 번 누르면 실행됩니다.
   - 검은 창이 뜨고, 잠시 뒤 크롬 또는 엣지 창으로 화면이 열립니다.
   - 검은 창을 닫으면 프로그램이 꺼집니다.
   - "Windows 의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다(서명하지 않은 프로그램이라 나오는 안내).

조각이 맞는지 확인하려면, 합친 zip 의 SHA-256 이 아래와 같은지 보면 됩니다.
`c5243e0e34c124fa3b723cb7cdd502e9a30ee1024e2a44e56c9267c92648d002`
(PowerShell: `Get-FileHash PhysicalAI-Simulator.zip`)

## 시험해 볼 곳

| 어디 | 확인할 것 |
|---|---|
| 처음 화면 → [시뮬레이터로 시작] → [시뮬레이션만] | 1~2분 안에 열리는지 |
| 교육 → 지도 → 아무 차시 | 미션 카드 · 지금 할 일 · 블록 흐름(예상 → 해 보기 → 결과 → 왜) |
| 시뮬레이터 탭 | 관절 움직이기, 블록 코딩 실행 |
| 자료실 | 이론서 · 매뉴얼 PDF 열기 |
| ⚙ → 로봇 USB 만들기 | USB 를 꽂으면 목록에 나오는지 |
| `교사용 학급 서버.cmd` | 선생님 PC 에서 학급 서버가 켜지는지 |

배포 전에 이 브랜치에서 확인한 것: Linux 로 같은 프로그램을 띄워 처음 화면 · 시뮬레이터 · 수업 · USB 만들기 창이 열리는 것, 조각을 합친 zip 이 원본과 같은 것(SHA-256).
