## 새 로봇 준비 (로봇마다 처음 한 번, 모니터 · 키보드 없이)

1. 로봇 전원을 켜고 1분 기다려요.
2. **PC 랜 포트 ↔ 로봇 LAN 포트** 를 랜선 하나로 바로 이어요 (공유기 · 벽 랜선은 빼요. 랜 포트가 없는 노트북은 USB 랜 어댑터).
3. 프로그램 ⚙ 설정 → **[새 로봇 설치]** → 로봇이 붙을 Wi-Fi 이름 · 비밀번호 · 로봇 이름 → **[설치 시작]**.
   - "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 **[예]** (PC 랜 포트 주소를 설치하는 동안만 바꾸고 끝나면 되돌려요).
   - 공장 계정(sunrise / sunrise)으로 로봇에 들어가 설치하고 Wi-Fi 까지 맞춰요 (3~5분). 끝나면 로봇 ID · 주소와 **[이 로봇에 연결]**.
4. 안 되면: 로봇 키트 안 「처음 설치 (모니터로).txt」 순서대로 모니터 · 키보드로 (화면의 [그래도 안 되면] 에도 같은 순서).

그 뒤로 Wi-Fi 를 바꾸거나 로봇 프로그램을 업데이트할 때는 ⚙ → **[로봇 USB 만들기]** → USB 를 로봇에 꽂기.

## 지난 판 (10 월 25 일)

**다른 로봇팔 OMX-F** 와 **말로 만들기 (AI)** 가 들어갔어요.

1. **OMX-F (시뮬레이터만)**: 선생님 계정으로 로그인 → ⚙ → **다른 로봇팔 쓰기 (OMX-F)** → 모델 고르기에서 ROBOTIS OMX-F.
   조그(5관절 · 좌표) · 그리퍼 · 자세 · 블록 · Python 이 myCobot 과 같은 방식으로 움직여요. 끄면 myCobot 280 RDK X5 로 돌아가요.
2. **말로 만들기 (AI)**: 교사 PC 에서 `교사용 학급 서버.cmd` → 학급 관리 → **수업 도구 › 말로 만들기 (AI)**.
   - 아직 **API 키가 없어 실제로 답을 받지는 못해요.** 키를 넣는 칸 · 켜기 · 하루 횟수 · 모델 · 기록 화면을 먼저 봐 주세요.
   - 학생 화면: 학급 로그인 → 시뮬레이터 → [코딩] → 블록 위 **말로 만들기** 칸. 선생님이 켜지 않았으면 이유가 나와요.
3. 「기초 사용 매뉴얼 (교사용)」 5.8 에 말로 만들기 켜는 법을, 설정 메뉴 표에 OMX-F 줄을 더했어요.
4. **AI 에게 시키기 (새로 바뀜)**: 이 PC 에 Ollama 와 모델(예: `qwen3:8b`)이 있으면, 오른쪽 작업 패널 머리줄에 **[✦ AI]** 가 나와요
   (왼쪽 메뉴 작업 › AI 로도 열려요). 대화는 오른쪽 패널에서 하고 로봇팔은 가운데 3D 에 그대로 보여요.
   - **"빨간 블록 집어"** → 바로 시뮬레이션으로 움직이고, 끝나면 결과(끝까지 갔는지 · 어디서 멈췄는지 · 한계에 가까웠던 관절)를 알려 줘요.
   - **"로봇 앞에 놔"**, **"5cm 위로"**, **"조금 더 왼쪽"** → AI 가 블록 · 손끝 좌표를 알고 있어서 이름 없는 자리도 돼요.
   - **"J3 에 무리가 가는데?"**, **"왜 멈췄어?"** → 지난 결과를 보고 설명하고, 고칠 동작을 [▶ 이렇게 해 보기] 로 붙여요.
   - **"방금 한 걸 블록으로 짜 줘"** → 블록 프로그램을 만들어 [블록 편집기에 넣기] 로 넣어요. 실제 로봇은 지금처럼 [로봇 실행] 으로만.
   - 빨간 블록(로봇에서 약 14cm)을 집으면 J3 가 한계까지 1° 남는 것을 확인했어요: 이 팔은 책상 높이에서 17~28cm 가 편한 거리예요.
5. **학급 서버로 쓸 때 (이 PC 의 Ollama)**: 교사 PC 에 Ollama 와 모델(예: `qwen3:8b`)이 있으면, 학급 관리 › 말로 만들기 (AI) 의 **AI 종류** 에서
   [이 PC 의 Ollama] → 모델 확인 → [말로 만들기 켜짐] → [저장]. 키와 인터넷 없이 같은 흐름이 돼요.
   답이 느리고(그래픽카드가 없으면 수십 초) 더 자주 틀려요. 틀린 줄은 블록 검사가 막아요. 시연 전에 한두 번 미리 물어 두세요.

- 순서: [✦ AI] 를 열고 "빨간 블록 집어" → "로봇 앞에 놔" → "J3 에 무리가 가는데?" → "블록으로 짜 줘" 순서로 이어서 말해 보세요
- 고침: 블록을 든 채 다른 실습(검수 시연 등)으로 바꾸면 블록이 화면에 남던 것
- 소스: `main` 커밋 64100a2 (10 월 26 일, 모델 바꾸기 오류), 로봇 키트 `20261026-003926-64100a2` (Ed25519 서명)
- 확인: 전체 시험 통과, 가짜 Ollama 로 집기 → 앞에 놓기 → 질문 → 블록 짜기 → 넣기 → 실패 안내까지 브라우저에서 확인. **실제 Ollama 모델로는 아직 확인 전**이에요
- **남은 것**: API 키 발급 뒤 실제 답 확인과 두 모델(Haiku 5.5 · Opus 5.5) 비교. OMX-F 실물 연결은 다음 단계예요.
