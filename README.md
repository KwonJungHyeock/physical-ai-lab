# Physical AI 시뮬레이터 — 시험판

Windows PC 에서 바로 실행하는 시뮬레이터 프로그램입니다. 인터넷이나 로봇 없이 동작합니다.

## 받는 법

1. 이 브랜치(`release`)의 **`PhysicalAI-Simulator.zip`** (약 95 MB)을 누르고 오른쪽 위 **Download** 를 누릅니다.
2. 받은 zip 을 풉니다(Windows 기본 압축 풀기 · 반디집 · 7-Zip 모두 됨).
3. `Physical AI 시뮬레이터` 폴더의 **`Physical AI 시뮬레이터.exe`** 를 두 번 누릅니다.
   - 검은 창이 뜨고, 잠시 뒤 크롬 또는 엣지 창으로 화면이 열립니다. 검은 창을 닫으면 꺼집니다.
   - "Windows 의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다(서명하지 않은 프로그램이라 나오는 안내).

이 zip 에는 **로봇 USB 만들기용 키트가 빠져 있습니다**(⚙ → 로봇 USB 만들기가 '키트 없음' 으로 나옴).
GitHub 는 100 MB 넘는 파일을 올릴 수 없는데, 키트(약 106 MB)를 넣으면 zip 이 200 MB 가 되기 때문입니다.
나머지 기능(교육 · 시뮬레이터 · 라이브러리 · 자료실 · 교사용 학급 서버)은 모두 들어 있습니다.

USB 만들기까지 시험하려면 `usb-kit-included/` 폴더의 키트 포함판을 받습니다.
세 조각(`.001` ~ `.003`)과 `join.cmd` 를 같은 폴더에 받아 `join.cmd` 를 두 번 누르면 zip 하나가 됩니다.
