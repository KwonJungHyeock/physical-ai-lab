처음 설치 — 모니터 · 키보드로 (PC 프로그램의 [새 로봇 설치] 가 안 될 때만)
=====================================================================
보통은 이 메모가 필요 없어요. PC 의 「Physical AI 시뮬레이터」 → ⚙ 설정 → [새 로봇 설치] 에서
랜선 하나로 PC 와 로봇을 이으면 프로그램이 알아서 설치해요 (모니터 · 키보드 필요 없음).
그게 안 될 때만 이 순서대로 하세요. 로봇마다 한 번이면 돼요.

준비물: 모니터(HDMI 선) · 키보드 · 마우스 · 이 USB (eduino 폴더가 맨 위에 있는 것)

1. 로봇 전원을 끈 채로 모니터 · 키보드 · 마우스를 로봇에 꽂아요.
2. 이 USB 를 로봇에 꽂고 전원을 켜요. 1분쯤 뒤 바탕화면이 나와요.
   로그인을 물으면  사용자 sunrise  /  비밀번호 sunrise
3. 터미널을 열어요:  Ctrl + Alt + T  를 함께 누르기
   (안 열리면 화면 왼쪽 위 메뉴에서 '터미널' 또는 'Terminal')
4. 아래 한 줄을 그대로 쳐요. 띄어쓰기 · 따옴표까지 똑같이, 다 치고 Enter.

   sudo python3 "$(find /media /mnt -maxdepth 6 -path '*eduino/install.py' 2>/dev/null | head -1)"

   - 치기 어려우면: 바탕화면에서 USB → eduino 폴더 → '설치하기' 를 두 번 눌러도 돼요
     (로봇에 따라 글자 편집기로 열리면 닫고 위 한 줄을 치세요).
5. [sudo] password for sunrise:  가 나오면  sunrise  를 치고 Enter.
   글자가 화면에 안 보여도 정상이에요.
6. [1/4] ~ [4/4] 가 차례로 지나고 "끝났어요." 가 나오면 성공이에요.
   맨 아래의 로봇 ID 와 주소를 적어 두세요 (USB 의 result-로봇이름.txt 에도 남아요).
   로봇이 살짝 움직였다 돌아와요.
7. 모니터 · 키보드를 빼요. 이제 PC 시뮬레이터에서 [로봇 연결] 로 찾을 수 있어요.

안 될 때
- 4번 뒤에 아무 일도 없거나 'No such file' → USB 가 아직 안 열린 것이에요.
    sudo mount /dev/sda1 /mnt     를 치고 Enter, 그다음 4번을 다시 해요.
- 'Sorry, try again' → 비밀번호가 틀렸어요. sunrise 를 다시 천천히 쳐요.
- 그래도 안 되면 화면을 사진으로 찍어 보내 주세요.
