에듀이노 USB 키트 — 로봇을 교실 Wi-Fi 에 붙이기
==============================================
그림으로 된 안내: 「시뮬레이터 사용 매뉴얼.pdf」 10장 (실제 로봇과 연결하기)

이 USB 의 eduino 폴더:
  wifi.txt            로봇이 붙을 Wi-Fi 이름·비밀번호와 사용자 이름 (이것만 고치면 돼요)
  설치하기            로봇 화면에서 더블클릭 (로봇마다 처음 한 번)
  install.py          설치 파일 (설치하기 가 이걸 실행해요)
  robot_console.zip   로봇 콘솔 프로그램 (install.py 가 풀어요)
  result-<로봇이름>.txt  꽂은 뒤 로봇이 써 주는 결과 (로봇 ID·주소)

----------------------------------------------
A. 로봇마다 처음 한 번 (5분)
----------------------------------------------
1. PC 에서 wifi.txt 를 메모장으로 열어 교실 Wi-Fi 와 사용자 이름을 적고 저장합니다.
      와이파이=EDUINO-LAB
      비밀번호=12345678
      사용자=3조 김민수      (PC 의 [로봇 찾기] 목록에 IP 와 함께 보일 이름)
2. USB 를 로봇에 꽂습니다.
   [로봇에 모니터·마우스가 있으면 — 더블클릭]
   - 로봇 화면에서 USB 의 eduino 폴더를 열고 '설치하기' 를 더블클릭.
   - "Untrusted application launcher(신뢰할 수 없는 실행 파일)" 가 뜨면 [Launch Anyway / 그래도 실행].
   - 검은 창에서 비밀번호를 물으면 로봇 계정 비밀번호 + Enter (글자가 안 보여도 정상).
   - 맨 아래에 주소가 나오면 끝. Enter 로 창을 닫아도 서버는 로봇 안에서 계속 켜져 있어요.
   그러면 아래 3번은 건너뛰고 4번으로.
   [모니터 없이 SSH 로 접속했으면 — 명령 한 줄]
3. 아래 한 줄을 그대로 입력합니다. 비밀번호를 물으면 로봇 계정 비밀번호.
      sudo python3 /media/*/eduino/install.py
   - "No such file" 이 나오면 USB 가 다른 곳에 열린 것 — 이 줄로 찾아 실행합니다:
      sudo python3 "$(find /media /mnt -maxdepth 4 -path '*eduino/install.py' 2>/dev/null | head -1)"
   - 로봇팔(RDK X5)은 저절로 알아봅니다. 라즈베리 파이 보드면 myAGV/로봇팔을 물어봅니다 (Enter = myAGV).
   - 그래도 안 되면 USB 가 아직 열리지 않은 것:  sudo mount /dev/sda1 /mnt  후
        sudo python3 /mnt/eduino/install.py
4. 끝나면 로봇이 살짝 움직이고(로봇팔은 밑동이 살짝 돌았다 돌아옴, myAGV 는 제자리에서 살짝 돌기),
   USB 의 result-<로봇이름>.txt 에 로봇 ID 와 주소가 적힙니다.
   로봇 핫스팟으로 SSH 접속 중이었다면 창이 끊기는데, 정상이에요. 결과 파일을 보세요.

----------------------------------------------
B. 그 뒤로 — Wi-Fi 가 다른 곳에 수업 갈 때
----------------------------------------------
1. PC 에서 wifi.txt 의 와이파이·비밀번호(·사용자)를 고쳐 저장합니다.
2. 로봇 전원을 켜고 1분 뒤 USB 를 꽂습니다. (터미널 필요 없음)
3. 로봇이 살짝 움직이면 연결 끝. 10초쯤 뒤 USB 를 빼서 PC 에서 결과 파일을 확인합니다.
   (팔 전원이 꺼진 로봇팔은 안 움직여요. 결과 파일이 '성공' 이면 연결된 거예요.)
   - USB 하나로 여러 대를 차례로 꽂아도 돼요. 로봇마다 결과 파일이 따로 생겨요.
   - 이미 이 wifi.txt 로 연결한 로봇은 다시 꽂아도 그대로 둡니다.
   - 실패하면 로봇은 원래 연결(로봇 핫스팟)로 돌아가요. 결과 파일의 이유를 보고
     wifi.txt 를 고쳐 다시 꽂으면 다시 해요.
4. 한 번 붙은 Wi-Fi 는 로봇이 기억해서, 그 교실에서는 전원만 켜면 저절로 붙어요.
   그 Wi-Fi 가 없는 곳에서는 로봇 핫스팟이 켜져요.

로봇 핫스팟으로 되돌리기:  wifi.txt 에  와이파이=핫스팟  으로 저장하고 꽂기.

----------------------------------------------
PC 에서 접속
----------------------------------------------
PC 를 같은 Wi-Fi 에 연결 → 'Physical AI 시뮬레이터.exe' 더블클릭
→ 처음 화면에 로봇 목록이 저절로 나와요 (사용자 이름 · IP · 로봇 ID)
→ 내 로봇의 [연결] → 바로 실습.  (또는 결과 파일의 PC 브라우저 주소를 열기)

알아 두기
- 공유기의 2.4GHz 를 켜 두면 가장 확실해요 (5GHz 도 대부분 됨).
  접속할 때 웹 로그인 화면이 뜨는 Wi-Fi(학교·기관 인증)는 안 돼요.
- 공유기의 "AP 격리 / 게스트 격리" 는 꺼 두세요. 켜져 있으면 PC 가 로봇을 못 찾아요.
- Wi-Fi 이름은 대소문자·띄어쓰기까지 똑같이 적어요.
- 이 USB 에서 로봇은 Wi-Fi 이름과 비밀번호만 읽어요 (프로그램은 사람이 '설치하기' 를 눌러 비밀번호를 넣을 때만 실행).
