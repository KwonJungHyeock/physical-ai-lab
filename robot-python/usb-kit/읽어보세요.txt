에듀이노 USB 키트 — 로봇을 교실 Wi-Fi 에 붙이고, 로봇 프로그램을 최신으로
=====================================================================
그림으로 된 안내: 「시뮬레이터 사용 매뉴얼.pdf」 10장 (실제 로봇과 연결하기)
이 USB 는 PC 의 「Physical AI 시뮬레이터」 프로그램 → ⚙ 설정 → [로봇 USB 만들기] 로 만들 수 있어요
(Wi-Fi 를 칸에 적으면 프로그램이 이 폴더와 wifi.txt 를 써 줘요. 꽂았던 USB 를 다시 꽂으면 결과도 보여 줘요).

이 USB 의 eduino 폴더:
  wifi.txt               로봇이 붙을 Wi-Fi 이름·비밀번호와 사용자 이름 (이것만 고치면 돼요)
  install.py             처음 설치 파일
  robot_console.zip      로봇 콘솔 프로그램 (.sig = 서명: 로봇이 진짜 키트인지 확인)
  result-<로봇이름>.txt  꽂은 뒤 로봇이 써 주는 결과 (로봇 ID·주소·버전)

----------------------------------------------
A. 로봇마다 처음 한 번 — 터미널에서 한 줄
----------------------------------------------
1. PC 에서 wifi.txt 를 메모장으로 열어 적고 저장합니다.
      와이파이=EDUINO-LAB
      비밀번호=12345678
      사용자=3조 김민수      (PC 의 [로봇 찾기] 목록에 보일 이름)
2. USB 를 로봇에 꽂고, 로봇 터미널(또는 SSH)에서 이 한 줄을 입력합니다.
   비밀번호를 물으면 로봇 계정 비밀번호 + Enter (글자가 안 보여도 정상).
      sudo python3 "$(find /media /mnt -maxdepth 6 -path '*eduino/install.py' 2>/dev/null | head -1)"
   - '설치하기' 를 더블클릭하면 로봇에 따라 실행되지 않고 글자 편집기로 열려요.
     그럴 때는 창을 닫고 위 한 줄을 쓰세요.
   - 로봇팔(RDK X5)은 저절로 알아봅니다. 라즈베리 파이 보드면 myAGV/로봇팔을 물어봐요 (Enter = myAGV).
   - 아무것도 안 나오면 USB 가 아직 안 열린 것:  sudo mount /dev/sda1 /mnt  후 위 줄을 다시.
3. 끝나면 로봇이 살짝 움직이고, 화면 맨 아래와 결과 파일에 로봇 ID·주소가 나와요.
   로봇 핫스팟으로 SSH 접속 중이었다면 창이 끊기는데, 정상이에요. 결과 파일을 보세요.

----------------------------------------------
B. 그 뒤로는 — USB 를 꽂기만 (터미널 필요 없음)
----------------------------------------------
1. PC 에서 wifi.txt 를 고쳐 저장합니다 (Wi-Fi 가 그대로면 안 고쳐도 돼요).
   새 키트를 받았으면 새 eduino 폴더를 USB 에 복사합니다 (wifi.txt 는 다시 적기).
2. 로봇에 USB 를 꽂습니다. 전원을 켜기 전이든 켠 뒤든 괜찮아요.
3. 1~2분 기다립니다. 로봇이 살짝 움직이면 끝.
   (로봇팔은 밑동이 살짝 돌았다 돌아옴, myAGV 는 제자리에서 살짝 돌기.
    팔 전원이 꺼진 로봇팔은 안 움직여요 — 결과 파일을 보세요.)
4. USB 를 빼서 PC 에서 result-<로봇이름>.txt 를 엽니다.
      결과:     Wi-Fi 연결 (성공 / 실패와 이유)
      버전:     로봇 프로그램 버전 (업데이트했으면  이전 → 지금)
      업데이트: 성공 / 이미 최신 / 서명 없음·잘못됨 / 실패 → 이전 버전으로 되돌림
   - USB 하나로 여러 대를 차례로 꽂아도 돼요. 로봇마다 결과 파일이 따로 생겨요.
   - 이미 한 것은 다시 꽂아도 그대로 둡니다. 실패했으면 고쳐서 다시 꽂으면 다시 해요.
   - 업데이트가 실패하면 로봇은 이전 프로그램으로 저절로 돌아가요.

로봇 핫스팟으로 되돌리기:  wifi.txt 에  와이파이=핫스팟  으로 저장하고 꽂기.
랜선(유선)으로만 쓰기:     wifi.txt 에  와이파이=끔  으로 저장하고 꽂기. 로봇 Wi-Fi 가 꺼져요.
  - 공유기·허브에 랜선으로 꽂으면 [로봇 찾기] 로 보여요.
  - PC 와 랜선 하나로 바로 이으면 1분 뒤 연결 창의 [유선 직결] (로봇 주소 169.254.127.10).

----------------------------------------------
PC 에서 접속
----------------------------------------------
PC 를 같은 Wi-Fi 에 연결 → 'Physical AI 시뮬레이터.exe' 더블클릭
→ 로봇 목록이 저절로 나와요 (사용자 이름 · IP · 로봇 ID) → 내 로봇의 [연결].
(또는 결과 파일의 PC 브라우저 주소를 열기)

알아 두기
- 공유기의 2.4GHz 를 켜 두면 가장 확실해요. 웹 로그인 화면이 뜨는 Wi-Fi(학교·기관 인증)는 안 돼요.
- 공유기의 "AP 격리 / 게스트 격리" 는 꺼 두세요. 켜져 있으면 PC 가 로봇을 못 찾아요.
- Wi-Fi 이름은 대소문자·띄어쓰기까지 똑같이 적어요.
- 로봇은 서명이 맞는 키트의 프로그램만 받아요. 다른 USB 에서는 Wi-Fi 이름·비밀번호만 읽어요.
- 이 방법으로 처음 설치하기 전부터 쓰던 로봇은, 새 키트로 A 를 한 번 더 하면 그 뒤로 B 가 돼요.
