■ 반영할 것 (우선순위)
 [1순위 — 검수 시연을 막는 것]
  1) 흡착 펌프 배선 확정 (검수 4·5)
     공식 RDK X5 문서는 펌프 상자 G2 → 37번(BOARD), 우리 매뉴얼은 G5 → 37번 → 실물로 확정 후 매뉴얼·점검 도구 정정.
     콘솔 [흡착 켜기] 로 바로 확인되게 점검 결과를 화면에 표시
  2) 실제 카메라 2대 (검수 3)
     서버가 USB 카메라를 모두 찾아 번호별로 제공(/api/camera.jpg?cam=), 콘솔 [실제 카메라] 를 키트·손 카메라 2개로,
     실물 [사진 찍기] 2장으로 검수 3 달성 표시
  3) 손 카메라로 찾아 집기 (검수 4, RDK X5 공식 방식)
     촬영 자세 → 손 카메라 색 인식 → 카메라 위치(관절 각도 + 카메라 플랜지 장착값)로 책상 좌표 계산 → 시뮬 검사 → 흡착.
     키트 고정 카메라가 없는 구성에서도 검수 4 가능
  4) AI 샘플 = 공식 YOLO (검수 6)
     공식 RDK X5 비전 키트의 yolo_demo 와 같은 YOLOv5s(ONNX)를 로봇 OpenCV DNN 으로 실행 → 물체 이름·박스·처리 시간 표시.
     모델 파일(약 28MB)은 USB 키트에 포함
  5) ROS 2 실물 경로 (검수 7)
     방법 A(권장): 콘솔 [ROS 2 로 실행] → 서버가 시리얼 포트를 잠시 내려놓고 공식 패키지(slider_control) 실행,
                  학생 노드의 /joint_states 로 로봇이 움직임, 끝나면 서버 복귀
     방법 B: 서버가 직접 /joint_states 를 받아 움직임 (포트 충돌 없음, 공식 패키지 대신 자체 노드)
     → 둘 다 "로봇에서 학생 코드를 실행" 하므로 허용 범위 결정 필요

 [2순위 — 검수 증빙과 안전]
  6) 검수 결과 기록: 항목별 시각·실측값(반복 오차 mm, 처리 시간, 사진)을 모아 1장 결과표(PDF/HTML)로 저장
  7) 검수 전 사전 점검 화면: 카메라 대수, OpenCV·ArUco, 펌프 핀, 그리퍼, ROS 2 설치를 한 번에 ✓/✗
  8) 비상정지 거리 측정(속도 30·50) → 정지 안내·속도 상한에 반영 (보고 #8 에서 속도 10 만 잼: 정지 후 3°)
  9) 엔드이펙터 교체 안내: "그리퍼 작업 끝 → 펌프로 바꿔 끼우세요 → 도구 선택" 단계 안내

 [3순위 — 정확도]
  10) 키트 카메라 실측(높이·위치·시야각)을 사진 1장으로 시뮬레이터에 반영 (제안서 1920×1080·110° vs 시뮬 640×480·48°)
  11) 손 카메라 방향(플랜지에 끼운 방향) 실측 → 3D 손 카메라 화면을 실물과 같게
