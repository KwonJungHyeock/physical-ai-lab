# 보고 #38 — 조그 패널 · 좌표 조그 검토 · 물리 늘 켜기 · 공정 동작 확인

작성: 2026-10-21

내려받은 시뮬레이터를 직접 써 본 피드백 다섯 가지를 검토하고 고쳤습니다.

## 1. 조그 패널이 작고 비어 보임

| 전 | 후 |
| --- | --- |
| 버튼 26 ~ 36 px, 화살표(‹ ›)만. 뜻(앞 · 뒤 …)은 마우스를 올려야 보임 | 버튼이 패널 높이를 채움(한 줄 52 ~ 112 px). 버튼에 **뒤 · 앞 · 오른쪽 · 왼쪽 · 아래 · 위** 와 X− · X+ 를 함께 씀 |
| 위치 · 회전이 반씩 나란히, 아래 절반은 빈칸 | 위아래로 **손끝 위치** 3줄 → **손 방향** 3줄. 줄마다 [− 버튼 · 값 · + 버튼] |
| 관절: 고른 관절 하나만 크게, 나머지는 작은 줄 | 관절 여섯 줄이 모두 같은 크기. 줄마다 돌리기 버튼(−5° · +5° 처럼 한 칸 표시) · 각도 · 막대 |
| 회전 RX · RY · RZ 의 뜻을 알기 어려움 | 줄 이름 옆에 **좌우 기울기 · 앞뒤 기울기 · 돌리기**, 그리고 **[손 아래로]**(손을 똑바로 아래로, 손끝은 그대로) |

확인: 1920×1040 · 1366×768 · 1180×820(태블릿) 에서 조그 화면이 스크롤 없이 한 화면에 들어감.

## 2. 좌표 조그가 이 팔에 맞는 방식인가

결론: **맞습니다.** 다만 쓰는 자리가 있습니다.

- myCobot 280 은 6축이라 손끝을 X · Y · Z 로 곧게 옮기는 것이 수학적으로 됩니다. 실제 로봇 펌웨어도 같은 좌표 조그(`jog_coord`)를 가지고 있고, 시뮬레이터는 같은 계산(역기구학)으로 움직입니다.
- 시험(check:process): 손 방향 10° 돌려도 손끝은 0.5 mm 안에서 그대로, MOVE L 은 직선에서 0.42 mm 안.
- 어려운 이유는 방식이 아니라 화면이었습니다: 버튼에 방향이 안 쓰여 있었고, 손이 아래를 볼 때 RX 가 ±180 으로 보이는 것이 낯설고, 손 방향을 돌리다 헷갈리면 되돌릴 버튼이 없었습니다. 1장에서 고쳤습니다.
- 팔이 작아(손끝이 닿는 거리 약 28 cm) 너무 멀거나 로봇 바로 위 · 아래는 좌표로 못 갑니다. 그때는 움직이지 않고 이유를 알려 줍니다. 크게 옮길 때는 [관절], 블록 위에 맞출 때는 [좌표] 가 알맞습니다(매뉴얼에 적음).

## 4. 공정이 제대로 동작하는가

- 공정 실행(MOVE J · MOVE L · 그리퍼 · 대기, Tick · Smooth)은 시험으로 확인되어 있었습니다.
- **문제를 찾았습니다.** 예제 「집어서 옮기기」가 블록이 없는 자리(x 180, y −80)에서 그리퍼를 닫아 아무것도 집지 않았고, 공정 화면은 매트(블록)가 없는 빈 책상이었습니다. 팔은 움직였지만 "옮기기"는 되지 않았습니다.
- 고친 것: 예제가 매트의 초록 블록(x 185, y −25)을 집어 자리 2(x 190, y −100)에 놓도록 점을 다시 잡았고, 공정 화면을 열면 매트와 블록이 놓입니다.
- 확인: 시험이 이제 블록이 자리 2 에 놓였는지 봅니다. 앱에서도 [도구] 어댑티브 그리퍼 → [공정] → 예제 → [▶ 시뮬레이션] 으로 초록 블록이 옮겨지고 "시뮬레이션 성공"이 뜹니다.

## 5. 물리 엔진 늘 켜기 · 바닥에 박히지 않게

원인: 관절 막대나 3D 관절 끌기는 팔이 제 몸에 닿을 때만 막고, 책상에 닿아도 그대로 움직였습니다. 또 관절 중심만 봐서 팔 몸통(두께 약 40 mm)은 책상 속으로 들어갈 수 있었습니다.

| 고친 것 | 이제 |
| --- | --- |
| 책상 검사에 팔 몸통 두께 포함 | 프로그램 · 조그 · 막대 모두 팔이 책상 위에서 멈춤 |
| 막대 · 3D 끌기 | 닿는 바로 앞 자세에서 멈춤(책상 속으로 안 들어감). 이미 닿아 있으면 빠져나오는 쪽은 움직임 |
| 물리 켜기 · 끄기 | 선택을 없애고 늘 켬. 팔 몸통은 물건을 밀고, 손끝 도구는 집을 물건이 아니면 멈춤 |
| 집기 | 시뮬레이터가 정확히 집고(실제 도구와 같은 규칙), 물리는 그 물건을 손끝에 고정해 따라가게 함. 놓으면 그 자리에서 떨어짐 |

실제 서보는 책상을 밀어내며 튕기지 않고 그 자리에서 멈추므로, 시뮬레이터도 "멈춤 + 이유 알림"으로 했습니다.

확인: ▶ 데모 4개(실험실 · 제조 라인 · 물류 · 서비스)를 물리를 켠 채 브라우저에서 끝까지 실행 — 블록이 트레이에, 부품이 OK 함에, 상자가 팔레트에, 컵이 접시 옆에. 전체 시험(npm run check) 통과.
