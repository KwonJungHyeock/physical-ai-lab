## 3. 검수 7종 리허설 — 데모 로봇 서버로 전 경로

로봇 서버를 데모 모드(가짜 팔)로 켜고, 카메라 2대 자리에 그림 두 장(키트 카메라: 카페 장면 사진, 손 카메라: 블록 4개를 공식 손-눈 보정으로 그린 그림)을 넣었습니다.
화면은 로봇이 주는 콘솔(`/console`)을 실제 브라우저로 열어, 교육 → 로봇 실습 7 → 단원마다 [실물로] 단추를 사람이 누르는 순서대로 눌렀습니다.
도구: `web-typescript/tools/check/p7-real.mjs` (1600 × 900).

| 검수 | 누른 단추 | 결과 (화면에 나온 그대로) | 걸린 시간 |
| --- | --- | --- | --- |
| 1 전 축 구동 | 실물로 6축 움직이기 | 관절 6개 모두 ±30° 움직임 · 명령과 잰 각도 차이 최대 J2 0.1° | 42 s |
| 2 반복 위치제어 | 실물로 5번 다녀오기 | 같은 점에 5번 도착 · 흩어진 폭 0.3 mm | 65 s |
| 3 영상 취득 | 실제 카메라 2대로 찍기 | 실제 카메라 2대로 사진 (640×480, 640×480) | 20 s |
| 4 비전-로봇 연계 | ① 실제 블록 찾기 → ② 시뮬레이션으로 확인 → ③ 실물로 옮기기 | 블록 4개 찾음: 빨강 (115, −75) · 초록 (165, −75) · 파랑 (115, −20) · 노랑 (165, −20) — 그림에 놓은 자리와 0.1 mm 안. 4개를 색깔별 상자로 옮김 (끝까지 실행) | 152 s |
| 5 엔드이펙터 교체 | ① 그리퍼 열기 · 닫기 → 바꿔 끼웠어요 → ② 펌프 켜기 · 끄기 | 그리퍼 열기 · 닫기, 흡착 펌프로 바꿔 끼운 뒤 켜기 · 끄기 | 25 s |
| 6 AI 샘플 로컬 실행 | 로봇 안에서 AI 실행 | YOLOv5s 321 ms · 컵 80 %, 꽃병 80 %, 의자 74 %, 식탁 49 % | 18 s |
| 7 ROS 2 · API 실행 | 같은 코드를 실물로 실행 | 파이썬 API 명령 4줄을 로봇에서 끝까지 실행 | 20 s |

- 페이지 오류 0. 이어서 [검수 준비 점검] → [검수 결과표 저장] 까지 확인했습니다.
- 리허설 중 찾은 것: 검수 4 의 블록 자리가 처음에는 30~60 mm 어긋났습니다. 원인은 앱이 아니라 시험용 그림을 만든 점검 도구(`check_hand_camera.py`)의 옛 자세 값이었습니다(펌웨어 도구 좌표 회전 반영 전). 도구를 고친 뒤 0.1 mm 안으로 맞았습니다.
- 이 리허설은 **가짜 팔**로 한 것이라, 이 결과표는 새 기준에 따라 "◇ 데모 로봇" 으로 표시되고 실제 로봇 검수 수에는 들어가지 않습니다.

### 실제 로봇에서만 확인되는 것 (11월 검수 전에 실물로 한 번)

| 항목 | 왜 | 확인 방법 |
| --- | --- | --- |
| 흡착 펌프 배선 (G2 · G5 → 31 · 37번) | 공식 문서와 키트 표기가 다름 | [흡착 켜기] 에 모터 소리, 안 나면 `pump_check.py` |
| 카메라 2대 동시 사용 | 실물 USB 카메라 두 대의 대역폭 · 번호 | 검수 준비 점검 "카메라 2대 연결됨" |
| 손 카메라 블록 위치 오차 | 실물 손-눈 보정은 개체마다 조금 다름 | 검수 4 에서 찾은 자리 ↔ 자로 잰 자리 (5 mm 안이면 흡착 가능) |
| YOLOv5s 시간 | 데모는 PC CPU. 로봇 CPU 에서는 더 느림 (처음 한 번은 모델 읽기) | 검수 6 의 ms |
| ROS 2 (검수 7 의 ROS 2 쪽) | 로봇에 ROS 2 Humble · 공식 패키지가 없음 | 방식 결정 필요 (보고 #13: A 로봇에 설치 / B PC 에서) — 파이썬 API 쪽은 준비됨 |

## 5. 남은 것 · 결정이 필요한 것

- ROS 2 실물 경로 방식(A/B) 결정 — 검수 7 의 ROS 2 쪽.
- 흡착 펌프 배선을 실물로 확정한 뒤 매뉴얼 표기 하나로.
- 실물 로봇 결과를 선생님 화면(학급 관리)에 모으기: 지금은 "실물로 했음" 만 가고 측정값은 가지 않음.
- 한 로봇을 두 PC 가 동시에 열 때 누가 움직이는지 정하는 장치 없음 (지금은 수업 약속: 로봇 담당 한 명).
- 실물 연동의 그리퍼 종류는 화면에서 고른 도구를 따름 (실제로 끼운 것과 다르면 안내 필요).
- 시뮬레이터 사용 매뉴얼 · 교사 가이드의 화면 그림 일부가 10월 초 화면 (다음 판에서 다시 찍기).
