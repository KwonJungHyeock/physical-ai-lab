# 보고 #21 — 3D 모델 자산: 현황 목록과 바꿀 순서 (1단계)

> 현장 실습 7곳·로봇 시티 지도·시뮬레이터 작업대에서 **코드로 만든 3D 소품**을 모두 뽑아,
> 무엇을 모델 파일로 바꾸면 좋아지는지와 그 순서를 정리했습니다.
> 2단계(후보 모델 수집·비교)와 3단계(자산 라이브러리), 4단계(현장별 교체)의 기준이 됩니다.
> 앱 코드는 이 단계에서 바꾸지 않았습니다.

- 지금 앱 전체 그림·모델은 `public` 43 MB, exe는 117 MB입니다.

## 2. 나누는 기준

| 분류 | 뜻 | 바꾸는 방법 |
| --- | --- | --- |
| **A 판정 물체** | 엔진이 크기 · 위치로 판정하는 물체 (상자, 팔레트, 컨베이어, 시험관, 토마토, 컵, 재활용품 등) | **치수는 엔진 값 그대로**, 겉모습 · 재질만 바꿈. 판정 숫자는 바뀌지 않음 |
| **B 현장 기계 · 가구** | 이야기에 나오는 장비와 가구 (에스프레소 머신, 원심분리기, 침대, 선반 등) | 모델 파일로 교체 (실제 치수로 맞춤) |
| **C 사람** | 손님 손, 어르신 등. 지금은 손 하나만 있음 | 자세가 있는 사람 모델 (앉기 · 서기 · 손 뻗기) |
| **D 건물 · 방** | 벽, 창, 기둥, 바닥 | 실내 키트 + 바닥 · 벽 재질(텍스처) |
| **E 움직이는 소품** | 신호등, 팬, 모니터, 김, 회전등 | 대부분 그대로 (움직임은 코드가 맡음). 겉모양만 필요하면 교체 |

우선순위: **1순위** = 화면에 크게 보이고 지금 가장 어색함 · **2순위** = 보이지만 덜 어색함 · **3순위** = 작거나 멀리 있음.

## 5. 모델과 별개로 고칠 것 (설계)

- **돌봄 방 높이:** 팔 받침 = AGV 윗면이라 탁자가 바닥에서 13 cm입니다. AGV 위에 받침 기둥을 두어 팔 높이를 실제 협탁(약 60 cm)에 맞추면, 판정 숫자는 그대로 두고 침대 · 탁자 · 사람을 실물 크기로 놓을 수 있습니다.
- **사람의 크기:** 현장 셀은 로봇 실물 크기라 사람도 실물 크기여야 자연스럽습니다. 그러면 화면에 몸 일부만 보이므로 **카메라 구도와 함께** 정합니다(앉은 자세 · 화면 가장자리).
- **사람 수:** 현장마다 1~2명만, 이야기에 맞는 자세로 둡니다. 사람이 많으면 어색해지기 쉽고 계산도 무거워집니다.

## 7. 우선순위 요약

**1순위 (10건)** — 모으면 바로 차이가 큰 것
1. 사람: 돌봄 어르신(앉은 자세), 카페 손님(손 → 팔 · 몸), 공장 · 물류 작업자
2. 돌봄 방 가구: 침대, 협탁, 미니 냉장고, (휠체어)
3. 카페: 에스프레소 머신, 바 · 카운터
4. 바이오 실험실: 원심분리기, 시약장 · 실험대 · 폐기물통
5. 스마트팜: 토마토 줄 · 온실 실내
6. 현장 벽 · 창 (일곱 현장 공용)

**2순위** — 판정 물체 재질(상자 · 팔레트 · 시험관 · 토마토 · 재활용품), 창고 랙 · 물류 소품, 카페 가구, 연구소 책상 · 서버 랙, 바닥 텍스처, 시뮬레이터 장면 · AGV 교실

**3순위** — 센서 · 통 · 신호탑 같은 작은 소품, 지도

## 9. 자산 라이브러리 (3단계 설계안)

- **원본은 저장소 밖에 보관.** 원본 팩은 용량이 커서 지도 때처럼 내려받는 곳과 방법만 기록합니다(`tools/build/world-pack.mjs`와 같은 방식).
- **앱에는 최적화본만:** 실제 치수(mm)로 맞추고, 텍스처는 WebP로 줄이고, 갈래별로 GLB 하나에 묶습니다. 예: `public/models/care.glb`, `lab.glb`, `people.glb`.
- **출처 목록 하나:** 모델마다 출처 · 작가 · 라이선스 · 원래 주소 · 실제 치수 · 쓰는 장면을 적습니다. 새 콘텐츠를 만들 때 이 목록에서 고릅니다.
- **용량 상한:** 늘어나는 용량을 20~30 MB 안으로 잡습니다. 현장 화면은 처음 들어갈 때 만들어지므로, 현장별로 묶어 두면 한 현장의 모델이 무거워도 다른 현장을 열 때는 영향이 없게 할 수 있습니다.
- **라이선스:** CC0 우선. 출처 표기형(CC-BY)은 목록과 앱 정보 화면에 표기합니다. 라이선스 표기가 없는 무료 파일은 쓰지 않습니다.
