# 보고 #47 — 입문 기초편 커리큘럼 확정 (챕터 · 서브챕터 · 차시 · 수행평가)

학습 상품: **myCobot 280 협동로봇 입문 (생활 속 로봇)** · 슬러그 `mycobot280-cobot-basic` (에듀이노 AI 학습 상품).
대상: 고등학생 · 10차시 · 차시당 50분. 바뀌는 범위: 입문 트랙(`/track/life`)만. 풀버전과 `/console`은 그대로입니다.

## 원칙

- 서브챕터 버튼 하나 = 앱 장면 하나. 번호(1-1 ~ 6-2)는 교안의 장 · 절 번호와 같습니다.
- 세 현장(카페 · 캘리그라피 · 보드게임)은 같은 무게로: 현장 소개와 사이클 보기 → 해 보기 → 수행평가. 각 서브챕터 3개 · 2차시.
- 수행평가는 챕터마다 하나씩. 장면이 적은 서브챕터는 성격이 비슷한 것끼리 묶었습니다.
- 현장에 들어가기 전에 로봇 조작 기초(2장)를 먼저 익힙니다.

## 개발 순서

1. 수업 구조 데이터(챕터 · 서브챕터 · 장면 · 차시 · 평가 기준): 지금의 퀘스트 1–8 · 4/6/8차시 구조를 교체.
2. 공통 화면 틀: 위 챕터 · 서브챕터 내비(번호 = 교안 번호), 오른쪽 고정 패널, 아래 상태 한 줄.
3. 수행평가 기록: 상 · 중 · 하, 이유 쓰기, 기록 파일 · 반 결과에 포함.
4. 1-1 개념 카드 + 구분 퀴즈, 생성 이미지.
5. 현장 소개 화면(세 현장 공통), 캘리그라피 · 보드게임 장비 카드 이미지.
6. 사이클 보기 모드(단계 멈춤 + [다음 ▶] + 사이클 맵 강조): F1 · G1 · H1.
7. 2장: 튜토리얼 4개를 서브챕터에 연결.
8. 묶음 실행: F4 → F5, G2 → G3, H2 → H3.
9. 6-1 세 현장 비교 화면.
10. 교안 다시 만들기(계획서 · 지도안 / 교사용 / 학생용 + 6-2 학습지): 새 번호, 칸 안 글자 세로 가운데 · 넉넉한 줄 간격 · 큰 글자.
11. 기초편에서 숨김(심화편으로 보관, 코드는 그대로): F3(2-1과 겹침) · F6 반복 · F7 분기 · F8 운영.
