[보고 #4] myCobot 280 RDK X5 — 한국 초보자용 교육 도구: 동작 방식 추천

■ 한 줄 요약
"블록 → 파이썬" 3단계 학습 + "시뮬에서 먼저 → 통과하면 로봇에 업로드해 실행".
로봇교육 업계 표준(VEXcode, LEGO SPIKE, 엔트리)과 같은 흐름이고,
같은 코드가 시뮬과 실기에서 똑같이 도는 것이 핵심입니다.

■ 현황 진단
- 공식 ROS2 도구: UI는 영어, 중국어는 주석에만 있음 (simple_gui.py 528줄 중 29줄).
- 진짜 장벽은 언어보다 전제 지식: 터미널 실행, launch 명령, RViz 사용을 이미 안다고 가정.
→ 번역만으로는 부족하고, 초보자용 흐름을 새로 설계해야 합니다.

────────────────────────────────────────
1. 학습 단계 — 3단계 사다리
────────────────────────────────────────
 1단계  직접 움직이기 (코드 없음)
        - 슬라이더로 관절 조작
        - 드래그 티칭: 손으로 팔을 움직여 자세를 기록하고 재생
          (SDK: release_all_servos / focus_all_servos + get_angles로 구현 가능.
           RDK X5 클래스에는 공식 녹화 함수가 없어 직접 구현)
        - 로봇과 화면이 실시간으로 함께 움직임
 2단계  블록 코딩
        - 한국어 블록 (예: [관절 1을 30°로 이동])
        - 블록 옆에 변환된 파이썬 코드가 실시간 표시 → 3단계로 자연스럽게 넘어감
        - 엔트리/스크래치에 익숙한 학생이 바로 적응
 3단계  파이썬
        - 2단계와 같은 API를 직접 작성
        - 학교 정보 수업에서 가장 많이 쓰는 텍스트 언어라 교과 연계가 쉬움

────────────────────────────────────────
2. 실행 방식 — 추천 핵심
────────────────────────────────────────
 [코드 작성] → [시뮬레이션 실행] → 자동 안전검사 → [로봇에서 실행] → [■ 정지]

 (1) 같은 코드, 두 가지 실행 대상
     시뮬과 실기의 API가 동일하고 실행 대상만 바뀝니다.
     "시뮬에서 되면 로봇에서도 된다"가 성립해야 교육이 됩니다.
 (2) 시뮬 통과 전에는 [로봇에서 실행] 비활성
     관절 한계 초과, 바닥 충돌(z<0), 작업영역 밖 이동이 시뮬에서 걸러지기 전에는
     실기 실행을 막습니다. 초보자 사고를 막는 가장 확실한 장치입니다.
 (3) 로봇에서 실행 = 업로드 후 로봇 위에서 실행
     마이크로비트나 LEGO SPIKE처럼 코드를 로봇으로 보내 로봇 컴퓨터(RDK X5)에서 돌립니다.
     - 브라우저가 끊겨도 동작이 중간에 멈추지 않음
     - 나중에 카메라·AI(10 TOPS)를 로봇 위에서 바로 사용 가능
     단, 1단계(슬라이더·티칭)는 즉시 반응이 중요하므로 실시간 원격 조작으로 둡니다.
 (4) 비상정지 항상 노출
     화면 상단 고정 버튼 + 스페이스바. SDK의 stop()/pause()로 구현.
 (5) 교육 모드 안전값
     속도 상한(예: 50%), 관절 한계, 바닥·작업영역 제한을 기본으로 켭니다.
 (6) 교실 운영: 실행 대기열
     로봇 1대를 여러 학생이 쓰는 게 보통이므로 시뮬은 각자 무제한,
     실기 실행은 순서대로 대기열로 처리합니다.

────────────────────────────────────────
3. 화면 구조 — 한 화면 원칙
────────────────────────────────────────
 ┌──────────────────────────────────────────────────────────┐
 │ ● 로봇 연결됨   [▶ 시뮬 실행] [▶ 로봇에서 실행] [■ 정지]   │
 ├───────────────────────────┬──────────────────────────────┤
 │ 편집기                    │ 3D 로봇 (시뮬·실기 동일 표시) │
 │ [블록] [파이썬] 탭        │                              │
 ├───────────────────────────┴──────────────────────────────┤
 │ 실행 기록 (한국어): "3번 관절 200°는 범위(-150°~150°) 밖이에요" │
 └──────────────────────────────────────────────────────────┘
 - 터미널, launch 명령, RViz를 학생에게 노출하지 않음
 - 모든 에러를 "무엇이 / 왜 / 어떻게 고치는지" 한국어로 안내

────────────────────────────────────────
4. 초보자용 파이썬 API (안)
────────────────────────────────────────
 from edu import robot

 robot.home()                                   # 기본 자세
 robot.move_joints([0, -30, 45, 0, 30, 0], speed=40)
 robot.move_to(x=150, y=100, z=200)             # 좌표로 이동 (IK)
 robot.gripper.close()
 robot.wait(1)

 - 함수 이름은 영어로 둡니다 (실무·대학으로 이어지는 표준 표기)
 - 설명, 에러, 블록은 전부 한국어
 - 한국어 별칭(robot.기본자세())은 선택 사항

────────────────────────────────────────
5. 기술 구조 (요약)
────────────────────────────────────────
 [브라우저: 기존 Next.js 앱]
   편집기 + 3D 트윈 + 시뮬(브라우저 안에서 파이썬 실행)
        │ WebSocket (rosbridge)
 [RDK X5: ROS2 Humble]
   ├ 실행기 서비스: 코드 수신 → 격리 실행 → 로그 전송
   ├ 로봇 제어 노드: /dev/ttyS1, 1Mbps
   └ 안전 계층: 속도 상한, 한계, 비상정지
 - 브라우저 안 시뮬 덕분에 로봇 없이도(집에서도) 연습 가능
 - 브라우저용 파이썬 런타임의 초기 다운로드 용량은 스파이크에서 실측 후 확정

────────────────────────────────────────
6. 제약 사항
────────────────────────────────────────
 - 저는 클라우드 환경에 있어 실제 로봇에 직접 접속할 수 없습니다.
   실기 검증은 제가 스크립트를 준비하고, 로봇에서 실행한 결과를
   복사해 주시는 방식으로 진행합니다.
 - 280 AR(M5) Web Serial 트랙은 RDK X5를 주력으로 보고 보류로 가정합니다.
   병행이 필요하면 말씀해 주세요.
