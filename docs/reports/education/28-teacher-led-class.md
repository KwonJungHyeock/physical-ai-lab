## 2. 수업이 흘러가는 모습

| 누가 | 화면 | 하는 일 |
| --- | --- | --- |
| 선생님 (노트북 + 프로젝터) | 왼쪽: 프로젝터 화면 (큰 제목 · 한 줄 · 반 전체의 답 · 지금 할 일). 오른쪽: 진행 칸 (선생님만) | [다음 단계 열기] 로 반 전체를 넘김, 질문 · 예상 답, 정답 보이기, 로봇 허락, 모든 로봇 정지 |
| 학생 (1인 1PC) | 할 일 한 줄 + 그 아래 활동 + 맨 아래 "다 했어요" · [✋ 도움이 필요해요] | 고르기 · 사진 누르기 · 3D 따라 하기 · 예상하기. 지난 단계는 다시 볼 수 있고, 앞 단계로 먼저 갈 수 없음 |

| 모둠원 | 예상 고르기 + "우리 조 로봇" 상태 | 화면 대신 실물을 지켜봄 |

- 시작: 선생님 [교육] → [로봇 실습 7] → [선생님과 함께 수업] → 학급 · 수업 → [수업 시작].

- 정답은 선생님이 [모든 화면에 정답 보이기] 를 누를 때까지 학생 화면에 나오지 않습니다 (먼저 생각하고 답을 모은 뒤 함께 확인).
- 비상: [■ 모든 로봇 정지] 는 모든 조의 로봇 PC 에 정지를 보내고, 로봇 허락도 다시 잠급니다.
- 프로젝터를 **복제**로 쓰면 [진행 칸 숨기기] (작은 단추 ← → · 로봇 허용 · 정답만 남음). 프레젠터의 → · PageDown 도 됩니다.
- 학급 서버 없이: "이 PC 에서만" 으로 시작하면 프로젝터 화면만으로 같은 순서를 진행 (학생은 손을 들어 답).

## 5. 확인한 것 — 실제 브라우저 네 개로 7-4 한 시간

학급 서버를 새로 켜고 (교사 1, 학생 3), 브라우저 네 개를 따로 열었습니다: 선생님 (1600 × 900), 1번 = 1조 로봇 담당 (로봇이 주는 화면, 데모 로봇 서버), 2번 = 1조 모둠원, 3번 = 2조 모둠원 (1366 × 768).

| 단계 | 확인한 것 |
| --- | --- |
| 시작 · 참여 | 선생님이 시작하자 학생 교육 탭에 [함께하기], 조 · 역할을 고르면 3명 모두 1단계 화면. 진행 칸 "3 / 3명 들어옴" |
| 1 생각 열기 | 학생 고르기가 프로젝터 막대로 모임 (2명 · 1명) |
| 2 로봇 눈으로 보기 | 선생님이 넘기자 학생 화면이 함께 넘어감. 2번이 사진에서 블록 4개 → "다 했어요", 3번 도움 요청 → 진행 칸 "3번 ✋" |
| 3 자리 바꾸기 | 학생 A · B · C 고르기 → 정답 보이기 뒤 2번 "맞아요", 3번 "답은 B" |
| 4 화면에서 먼저 | 학생 화면 안의 3D 에서 [블록 찾기] → [색깔별로 넣기] 4개 → "다 했어요" |
| 5 실물로 | 허락 전 실물 버튼 잠김 (준비 끝이어도) → 허락 뒤 열림 → 실제 블록 찾기 → 시뮬레이션 확인 → 실물로 옮기는 중 [■ 모든 로봇 정지] → 로봇 PC 실행 멈춤 · 데모 로봇 서버 정지 · 허락 다시 잠김 → 다시 허락 → 끝까지 옮김. 진행 칸 "1조 끝", 모둠원 화면 "우리 조 로봇 끝" |
| 6 정리 | O · X 확인 문제 → 정답 보이기 → 다음 수업 (7-5) 으로 학생 화면이 함께 넘어감 → [수업 끝내기] → 학생 화면 "선생님이 수업을 끝냈어요" |

- 페이지 오류 0.
- 이 점검은 한 PC 에서 네 사람의 3D 를 소프트웨어로 그리느라, 점검 도구가 화면 갱신을 초당 8번으로 줄여서 돌립니다 (점검 환경 설정, 앱은 그대로).

## 6. 남은 것

- 실제 교실(Wi-Fi 공유기 하나, 학생 PC 20~30대)에서 1.5초마다 읽는 부하는 크지 않지만 (한 번에 1 KB 안팎) 실물 수업 전에 한 번 확인합니다.
- 한 조에 로봇 담당이 둘이면 번호가 작은 학생이 그 조의 로봇으로 보입니다. 같은 로봇을 두 PC 가 동시에 움직이지 못하게 막는 장치는 아직 없습니다 (수업 약속: 조마다 한 명).
- 선생님 화면의 학생 이름은 학급 관리의 번호 ↔ 이름 표가 있으면 함께 나옵니다 (이름은 선생님 PC 에만).
