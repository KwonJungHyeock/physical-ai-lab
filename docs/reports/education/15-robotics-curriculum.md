[보고 #15] 로봇공학 교육과정 기획 — 기구학 → 역기구학 → 자코비안 → 동역학 → 경로계획, 물리엔진 검토 (2026-10-02)

■ 핵심 요약
 - 목표: 대학원·전문 인력의 영역이던 로봇공학 이론을 고등~대학 수업에서 "움직여 보며" 익히게 한다.
   이론은 짧게(그림 1장 + 3줄), 체험은 3D 화면에서, 확인은 실물 로봇(myCobot 280 RDK X5)으로.
 - 순서: ① 기구학 → ② 역기구학(위치) → ③ 자코비안(위치+속도) → ④ 동역학(위치+속도+가속도) → ⑤ 경로계획 → ⑥ 종합: 3D 동역학 시뮬레이션
 - 지금 프로그램에 ①②⑤ 의 계산은 이미 들어 있음 (보이게 만드는 화면이 필요). ③ 은 계산만 있고 화면 없음. ④ 는 새로 필요 → 물리엔진.
 - 물리엔진 권장: 로봇 동역학 계산(자체 구현, 수식과 1:1) + 가벼운 강체 물리엔진 Rapier(접촉·마찰·바닥 정지).
   오프라인 exe·설치형 앱에도 그대로 들어감. MuJoCo 는 무거워서 대학 심화용 후보로 보류.

■ 2. 단원별 기획
 [1] 기구학 (Forward Kinematics) — "관절 각도를 주면 손끝은 어디에 있을까?"
  배우는 것   좌표계, 링크와 관절, 회전 + 이동 = 변환행렬, 관절을 차례로 곱하기(URDF/DH)
  3D 체험     관절 하나씩 돌리며 손끝 좌표(x, y, z) 변화 보기 · 관절마다 좌표축 표시 · 변환행렬을 관절 단위로 한 칸씩 쌓아 보기
              작업 공간: 손끝이 닿을 수 있는 공간을 3D 로 표시 (아래 3절)
  미션        각도 3개를 주고 손끝 위치를 먼저 예측 → 실행해서 확인 (오차 5mm 이내 통과)
  실물        같은 각도를 로봇에 보내고 로봇이 알려 주는 좌표(get_coords)와 비교
  지금        ● 관절 조그, 좌표축·관절축 표시, 공식 URDF 기구학(실물과 0.2mm 일치)   추가: 변환행렬 단계 보기, 3D 작업 공간

 [2] 역기구학 (Inverse Kinematics) — 위치 — "손끝을 여기 두려면 관절을 몇 도로?"
  배우는 것   거꾸로 풀기, 답이 여러 개(팔꿈치 위/아래)이거나 없을 수 있음, 반복해서 다가가는 수치 해법
  3D 체험     3D 에서 목표점을 끌면 팔이 따라옴 · 닿지 않는 곳은 빨간색 · 답을 찾아가는 반복 과정을 천천히 재생(오차가 줄어드는 그래프)
              같은 위치의 다른 답 2~3개를 반투명 팔로 비교
  미션        블록 위로 손 보내기 · 펜으로 사각형 그리기
  실물        좌표로 보내기(send_coords) 와 시뮬레이터 답(관절 각도) 비교
  지금        ● 수치 역기구학(자코비안 기반), 좌표 조그, 아래 보기 자세   추가: 반복 과정 재생, 여러 답 보기, 목표점 끌기

 [3] 자코비안 (Jacobian) — 위치 + 속도 — "관절을 조금 돌리면 손끝은 어느 쪽으로 얼마나 움직일까?"
  배우는 것   손끝 속도 = 자코비안 × 관절 속도, 특이점(어떤 방향으로 못 움직이는 자세), 움직이기 쉬운 정도(조작성)
  3D 체험     손끝에 속도 화살표 · 움직이기 쉬운 방향을 타원체로 표시 · 팔을 쭉 펴면 타원이 납작해지고 관절 속도가 치솟는 것 보기
  미션        손끝으로 직선 긋기(속도로 제어) · 색 블록 따라가기(카메라 화면의 자코비안)
  실물        직선 그리기, 손 카메라로 색 따라가기
  지금        ◐ 계산은 있음(역기구학 내부, 색 따라가기의 이미지 자코비안)   추가: 속도 화살표·조작성 타원체·특이점 경고 화면

 [4] 동역학 (Dynamics) — 위치 + 속도 + 가속도 — "움직이려면 힘(토크)이 얼마나 필요할까?"
  배우는 것   질량과 관성, 중력이 만드는 토크, 빨리 출발할수록 큰 토크, 모터 힘의 한계
              대학: 운동 방정식 M(q)q̈ + C(q,q̇)q̇ + G(q) = τ, 뉴턴-오일러 계산
  3D 체험     관절별 토크 막대 (팔을 뻗을수록 어깨 J2 토크가 커짐) · 블록을 들면 토크 증가
              위치·속도·가속도 그래프를 같은 시간축에 · 토크 한계를 넘으면 목표를 못 따라가고 늦어짐
              물리엔진: 블록이 떨어지고·밀리고·쌓이고·무너짐, 팔이 바닥/물체에 닿으면 멈춤(4절)
  미션        같은 위치를 가장 적은 토크로 버티는 자세 찾기 · "빠르게 vs 부드럽게" 가속도·토크 비교 · 블록 탑 쌓기
  실물        속도별 정지 거리 재기, 서보 부하 값 비교(로봇에서 읽을 수 있는지 확인 필요)
  지금        ○ 속도·가속도 곡선(5차 다항식)만 있음   추가: 동역학 계산 + 물리엔진 (가장 큰 신규 작업)

 [5] 경로계획 (Path Planning) — "부딪히지 않고, 매끄럽게 가려면?"
  배우는 것   관절 공간 경로 vs 직선 경로, 시간 계획(사다리꼴·5차), 장애물 피하기(RRT 등 탐색), 충돌 검사
  3D 체험     두 경로(곡선 vs 직선)의 손끝 궤적 비교 · 속도 그래프 비교 · 장애물을 놓으면 탐색 나무가 자라며 길을 찾는 모습
  미션        장애물을 피해 블록 옮기기 · 가장 빠른/가장 짧은 경로 대결
  실물        계획한 경로를 그대로 실행 (실행 전 충돌 검사 통과한 것만)
  지금        ◐ 5차 시간 계획, 직선 경로, 실행 전 충돌 검사   추가: 장애물 놓기, 경로 탐색 시각화, 속도 그래프

 [6] 종합 — 3D 동역학 시뮬레이션
  물리엔진을 켠 상태에서 집기 → 옮기기 → 쌓기를 설계 → 시뮬레이션 통과 → 실물 실행. 검수 시연(검수 4·5)과 연결

 차시 예시 (1차시 50분)
  단원          고등(블록)   대학(Python)   비고
  1 기구학       2            2              좌표계·변환행렬
  2 역기구학     2            3              대학: 반복 해법 직접 구현
  3 자코비안     2            3              대학: 자코비안 직접 계산·특이점
  4 동역학       2            3              대학: 중력 토크 계산
  5 경로계획     2            3              대학: RRT 빈칸 채우기
  6 종합         2            2              프로젝트
  합계          12           16

■ 3. 3D 화면 — 작업 반경과 배경
 - 지금: 바닥에 반지름 280mm 원판(설정에서 켜야 보임). 높이 방향은 안 보임
 - 바꿀 것
   · 3D 작업 공간: 관절 한계 안에서 손끝이 닿는 점을 미리 계산해 반투명 껍질로 표시 (위·옆에서 모양이 보이게)
   · 단원 1·2 에서는 기본으로 켬, 목표점이 작업 공간 밖이면 빨간색 + "닿지 않아요"
   · 관절별 회전 범위를 부채꼴로 표시 (관절 한계 = 왜 못 가는지)
   · 3D 배경: 실습 책상·바닥·조명이 있는 교실 장면 (지금은 회색 바닥 + 격자) — 크기 감 잡기용

■ 4. 물리엔진 검토
 4-1. 지금 상태
  - 기구학 시뮬레이션: 관절 각도를 시간에 따라 계산해 그림. 속도는 반영됨(속도 100 = 관절 최대 200°/s, 출발·정지 때 부드럽게 가감속)
  - 충돌: "실행 전 규칙 검사" — 팔이 책상 아래로 가거나 블록이 겹치는 동작은 실행 전에 멈추고 안내
  - 블록: 집으면 붙고 놓으면 그 자리에 놓이는 규칙. 질량·힘·마찰·넘어짐 없음
  → 의견(바닥에 닿으면 더 못 움직임, 관절 속도, 동역학 교육)을 채우려면 물리 계산이 필요함 — 동의

 4-3. 시뮬레이터에서 이렇게 움직이게 함
  - 실물 서보는 "목표 각도로 가려는 모터". 시뮬레이터도 관절마다 같은 모터(최대 속도·최대 토크 제한)로 움직임
  - 팔 링크마다 충돌 모양을 달아, 바닥·블록·장애물에 닿으면 접촉 힘이 생김
    → 모터 힘을 넘으면 그 자리에서 멈춤 + "J2 과부하 — 바닥에 닿음" 표시 (실물 서보가 걸려서 멈추는 것과 같은 모습)
  - 블록은 진짜 물체: 집게 마찰로 들고, 놓으면 떨어지고, 비뚤게 쌓으면 무너짐. 흡착은 흡입력 한계 안에서만 붙음
  - 관절 속도·가속도·토크를 그래프로 (단원 3·4·5 공통)
  - 물리 켜기/끄기 스위치: 끄면 지금처럼 가볍게(초급), 켜면 물리(단원 4~6)

 4-4. 필요한 값과 확인할 것
  - 공식 URDF 에 질량·관성 값이 없음 → 부품 3D 모델 부피로 나눠 추정하고 공식 무게·가반하중(250g) 사양에 맞춤
  - 서보 최대 토크·속도: 공식 사양값 사용, 실물로 비교(속도별 정지 거리 — 보고 #8 에서 속도 10 만 잼)
  - 실물 펌웨어는 접촉 감지가 없을 수 있음 → 시뮬의 "닿으면 멈춤"은 교육·안전 규칙으로 표시하고, 실물로 보내기 전 충돌 검사는 그대로 유지
  - 물리 결과는 실물과 똑같지 않음(추정 질량·단순 충돌 모양) → 화면에 "근사 모델" 표기, 값보다 경향(뻗으면 토크↑)을 가르침

■ 5. 진행 순서 (제안)
  1단계  작업 공간 3D 표시 + 교실 배경 + 속도·가속도 그래프              (단원 1·5 바로 쓸 수 있음)
  2단계  로봇 동역학 계산 + 관절 토크 막대 + 자코비안 화살표·타원체        (단원 3·4)
  3단계  Rapier 물리: 링크 충돌·바닥 정지·블록 물리, 물리 켜기 스위치      (단원 4·6)
