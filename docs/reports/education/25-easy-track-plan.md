# 25. 쉬운 실습 트랙 기획안: 초보 교사 · 고등 · 대학 입문용

> 시연 피드백 4번 "교육자료와 실습 가이드가 너무 어렵다. 과정이 많다. 대상은 고등 · 대학, 그리고 로봇공학
> 전문지식이 없는 초보 교사다"에 대한 기획안입니다. 지금 콘텐츠는 버리지 않고 **심화 과정**으로 남기고,
> 그 앞에 **누구나 5분 안에 첫 성공을 하는 입문 과정**을 새로 둡니다.

---

## 1. 지금 무엇이 어려운가 (진단)

| 항목 | 지금 | 초보 교사 · 학생이 느끼는 것 |
|---|---|---|
| 분량 | 이론 8학문 **28차시** + 현장 7곳 × 문제 3개 = **21문제** + 마무리 평가 | 어디서 시작해야 할지 모름 |
| 한 문제의 단계 | 작업 지시 → 가동 · 문제 → 원인 찾기 → 값 고치기 → 다시 가동 · 비교 → 해결 · 원리 (**6단계**) | 45분이 빠듯하고, 첫 성공까지 오래 걸림 |
| 한 문제의 글 | 원고 기준 약 **2,500자** (물류 문제 ①, 공백 제외) | 읽다가 지침 |
| 한 이론 차시의 글 | 원고 기준 약 **4,600자** (1-1 관절 · 링크 · 자유도) | 교사가 수업 전에 다 읽기 어려움 |
| 용어 · 수식 | 역기구학, F = m(g + a), HSV 문턱값, 호모그래피, 슬로싱 | 전공 용어가 먼저 나와 겁을 먹음 |
| 조작 | 측정 도구로 재기 → 계산 칸 입력 → 예상 고르기 → 가동 | "무엇을 눌러야 하지?" |
| 교사 준비 | 원고 + 지도안 + 정답 + 실물 연결(USB · Wi-Fi · 영점) | 수업 전날 준비가 길다 |

핵심은 **내용이 틀린 게 아니라, 입구가 높다**는 것입니다. 전공 수업 수준의 설계가 입문 대상에게 그대로 열려 있습니다.

## 2. 누구를 위한 것인가

| 대상 | 알고 있는 것 | 원하는 것 |
|---|---|---|
| 고등학생 (정보 · 기술 수업, 동아리) | 블록 코딩 경험 정도, 수식 부담 큼 | 로봇이 내 말대로 움직이는 재미, 짧은 성공 |
| 대학 1 ~ 2학년 (교양 · 공학 입문, 비전공 포함) | 간단한 계산 가능 | 산업 현장과 이어지는 실감, 과제로 낼 결과물 |
| 초보 교사 (로봇공학 비전공) | 수업 운영은 능숙, 로봇은 처음 | **30분 준비로 바로 할 수 있는 수업**, 막혔을 때 답 |

## 3. 설계 원칙 7가지

1. **5분 안에 첫 성공**: 화면을 열자마자 로봇이 내 손으로 움직인다. 읽기는 그 다음.
2. **한 차시 = 질문 하나, 3단계**: 해 보기 → 바꿔 보기 → 말해 보기. (지금 6단계 → 3단계)
3. **숫자 입력 대신 끌기 · 고르기**: 계산은 화면이 대신 보여 준다. 수식은 "더 알아보기"로 접어 둔다.
4. **비유 먼저, 용어는 나중에**: 좌표 = "로봇 손에게 주는 주소", 자유도 = "팔이 움직일 수 있는 방향의 수".
5. **화면이 판정**: 성공하면 ✓ 와 별이 바로 뜬다. 교사가 하나하나 확인하지 않아도 된다.
6. **교사는 한 장으로**: 말할 것 3문장, 보여 줄 것, 학생이 자주 묻는 질문과 답이 A4 한 장에.
7. **시뮬레이션에서 되면 실물도 같은 버튼으로**: 같은 블록 프로그램을 [로봇으로 실행] 하나로. 실물은 교실에 한 대면 충분.

## 4. 새 구조: 세 단계 트랙

```
 STEP 1  로봇과 친해지기 (입문 · 새로 만듦)      8개 미션 × 20 ~ 25분
    ↓
 STEP 2  현장 미션 라이트 (지금 현장 실습의 쉬운 판)  7곳 × 문제 1개, 3단계
    ↓
 STEP 3  심화 (지금 콘텐츠 그대로)              이론 28차시 · 현장 21문제 6단계 · 대학 Python
```

- 교육 홈(로봇 시티 지도) 첫 화면에서 **입문 / 현장 / 심화** 세 갈래를 고른다. 처음 들어온 사람은 입문으로 안내.
- 지금까지 만든 이론 · 현장 콘텐츠는 그대로 **심화**로 남는다. 대학 전공반 · 로봇 동아리 · 교사 연수 심화용.

## 5. STEP 1 로봇과 친해지기: 미션 8개

시뮬레이터에 이미 있는 기능(관절 조작, 좌표 이동, 자세 저장, 블록 코딩, 흡착 · 그리퍼, 카메라 색 찾기, 펜, 자동 판정)을
다시 쓰므로 새로 만들 부분이 적습니다.

| # | 미션 | 하는 일 (학생) | 성공 판정 (화면이 자동) | 배우는 것 (쉬운 말) | 이어지는 현장 | 지금 기능 |
|---|---|---|---|---|---|---|
| 1 | 로봇에게 인사하기 | 관절 6개를 하나씩 돌려 손 흔들기 | 관절 6개 모두 움직임 ✓ | 관절 = 로봇의 어깨 · 팔꿈치 · 손목 | 모든 현장 | 있음 |
| 2 | 로봇 손의 주소 | 앞뒤 · 좌우 · 위아래 버튼으로 손끝을 별 3개에 맞추기 | 별 3개 모으기 ✓ | 좌표 = 손에게 주는 주소 (x, y, z) | 물류 · 공장 | 판정만 추가 |
| 3 | 따라 해! 자세 기억시키기 | 로봇을 손으로 움직여 자세 3개 저장 → 재생 | 저장한 자세 3개로 이동 ✓ | 티칭 = 공장 로봇에게 일을 가르치는 가장 흔한 방법 | 공장 | 있음 |
| 4 | 블록으로 옮기기 | [위로 가기] [집기] [놓기] 블록 4 ~ 6개로 블록 옮기기 | 블록이 정해진 자리에 ✓ | 프로그램 = 순서대로 하는 일의 목록 | 물류 | 있음 |
| 5 | 탑 쌓기 | [반복 3번] 안에서 놓는 높이를 블록 높이만큼 올리기 | 3층 탑이 무너지지 않음 ✓ | 반복 + 높이 더하기 | 물류 팔레타이징 | 판정만 추가 |
| 6 | 빠르게? 천천히? | 속도 슬라이더를 바꿔 컵 옮기기 | 흘리지 않고 10초 안 ✓ | 빠르면 출렁인다 (속도 · 가속도의 감각) | 카페 · 바이오 | 카페 엔진 재사용 |
| 7 | 색깔 분류 | [카메라로 빨강 찾기] → [만약 빨강이면 A 상자] | 색깔별로 3개 분류 ✓ | 카메라가 보고 로봇이 판단 (조건) | 스마트팜 · AI · 자원순환 | 있음 |
| 8 | 나만의 로봇 작업 | 앞의 블록으로 자기 작업 만들기 (그림 그리기 · 정리하기 등) | 교사가 발표로 평가 | 배운 것 묶기 | 전체 | 있음 |

**미션 한 개 화면 (3단계)**

```
┌──────────────────────────────┬──────────────────────────────────────┐
│ 미션 5 · 탑 쌓기       ★★☆   │                                      │
│ "블록 3개를 무너지지 않게"    │              3D 로봇 (크게)            │
│                              │                                      │
│ ① 해 보기   지금 프로그램 실행 │        놓을 자리가 반투명으로 보임       │
│ ② 바꿔 보기 [높이 +40] 끌기   │                                      │
│ ③ 말해 보기 "왜 무너졌을까?"  │   ✓ 성공!  3층 탑 완성 (느린 재생 보기)  │
│     (보기 3개 중 고르기)       │                                      │
│ ─────────────────────────── │                                      │
│ 실제 현장: 물류센터 팔레타이징 │        [▶ 실행]  [로봇으로 실행]        │
└──────────────────────────────┴──────────────────────────────────────┘
```

- 글은 미션마다 화면 기준 **300자 안팎** (지금 현장 문제의 1/8 수준).
- 힌트는 두 번 실패하면 자동으로 하나씩 열림. 정답 범위는 넓게(예: 높이 38 ~ 45 mm 모두 성공).
- 각 미션 끝에 **실제 현장 적용 예** 한 줄 (이번에 현장 실습 화면에 넣은 카드와 같은 내용).

## 6. STEP 2 현장 미션 라이트: 지금 현장 실습을 쉽게

지금 현장 7곳의 **문제 ①만** 골라 3단계로 줄인 판입니다. 엔진 · 3D 장면 · 판정은 그대로 쓰고 화면 흐름만 바꿉니다.

| 지금 (6단계) | 라이트 (3단계) | 바뀌는 점 |
|---|---|---|
| 작업 지시 + 가동 · 문제 | **① 보기** | 상황 설명 3줄 → 그림 1장 + 한 줄. 바로 [가동] → 실패를 느린 재생으로 |
| 원인 찾기 + 값 고치기 | **② 고치기** | 측정 · 계산 칸 없음. 값 **1개만** 슬라이더로, 3D에 결과 미리보기(반투명) |
| 다시 가동 · 비교 + 해결 · 원리 | **③ 확인** | 다시 가동 → 전 · 후 비교 한 줄 → 원리 카드 1장 (수식은 접어 둠) |

- 예: 물류 ① "쌓다가 무너진다" → 라이트는 [층 간격] 슬라이더 하나. 40 근처로 옮기면 2층 · 3층 미리보기가 초록으로.
- 측정 · 계산 · 원인 고르기 · 예상하기는 **[심화로 풀기]** 버튼으로 지금 6단계 화면을 그대로 연다.

## 7. 교사 지원

| 자료 | 내용 | 분량 |
|---|---|---|
| 수업 한 장 (미션마다) | 목표 · 준비 · 시간표(도입 5분 · 미션 25분 · 정리 10분) · 말할 것 3문장 · 자주 묻는 질문 | A4 1장 |
| 첫 수업 체크리스트 | 프로그램 켜기 → 학생 로그인 → 미션 1 열기 (실물 없이 가능) | 반 장 |
| 10분 교사 영상 | 미션 1 ~ 3을 교사 눈높이로 따라 하기 (화면 녹화) | 10분 |
| 교사 화면 | 학생별 미션 진행(이미 있는 학급 계정 기능) + 막힌 학생 표시 | 앱 안 |
| 정답 보기 | 교사 계정에만 미션별 정답 프로그램 · 정답 값 | 앱 안 |

실물 로봇은 **교실에 한 대로 교사가 시연**하는 것을 기본으로 합니다. 학생은 시뮬레이션으로 하고, 성공한 모둠의 프로그램을
교사 로봇으로 [로봇으로 실행] 해 보는 식입니다. (실물 연결 설정은 교사가 수업 전에 한 번만)

## 8. 수업 묶음 예시

| 대상 | 묶음 | 구성 |
|---|---|---|
| 고등학교 정보 · 기술 | 4차시 | 미션 1 · 2 / 3 · 4 / 5 · 6 / 7 · 8 (한 차시에 미션 2개) |
| 고등 로봇 동아리 | 8주 | STEP 1 4주 → STEP 2 라이트 3곳 3주 → 발표 1주 |
| 대학 교양 · 공학 입문 | 8주 | STEP 1 3주 → STEP 2 라이트 4곳 4주 → 팀 과제 1주 (원하는 팀은 STEP 3 심화 1문제) |
| 교사 연수 (1일 6시간) | 1일 | 오전 STEP 1 전체 체험 → 오후 STEP 2 라이트 2곳 + 수업 한 장 실습 |

## 9. 지금과 바뀌는 숫자 (목표)

| 항목 | 지금 | 입문 트랙 목표 |
|---|---|---|
| 첫 성공까지 | 상황 · 기준표를 먼저 읽고, 6단계를 끝까지 가야 해결 | **3 ~ 5분 안에 첫 ✓** |
| 한 차시 단계 | 6단계 | **3단계** |
| 화면 글 (한 활동) | 약 2,500자 | **약 300자** |
| 수식 | 원리 단계에서 필수 | **선택 (더 알아보기)** |
| 교사 준비 | 원고 + 지도안 정독 | **수업 한 장 + 10분 영상 (30분 안)** |

## 10. 만드는 순서 (승인되면)

| 단계 | 기간 | 만드는 것 | 확인 |
|---|---|---|---|
| 1 | 1주 | 미션 화면 틀(3단계 · 자동 판정 · 별) + 미션 1 ~ 4 + 수업 한 장 4장 | 교사 2명이 준비 없이 미션 1 ~ 4 진행해 보기 |
| 2 | 1 ~ 2주 | 미션 5 ~ 8 + [로봇으로 실행] + 현장 라이트 (7곳 문제 ①) | 고등 1반 시범 수업 |
| 3 | 1주 | 시범 수업 피드백 반영, 교육 홈 세 갈래(입문 · 현장 · 심화), 10분 교사 영상 | 교사 설문: "어렵다" 응답 비율 |

**시범 수업에서 볼 것**: 교사가 30분 준비로 수업했는가 / 학생 80% 이상이 미션을 25분 안에 성공했는가 /
"어렵다"고 답한 학생 비율 / 막힌 지점(화면 기록으로 확인).

## 11. 정할 것 (의견 주세요)

1. 교육 홈 첫 화면을 **입문(STEP 1)** 으로 할지, 지금처럼 지도에서 고르게 할지
2. 실물 로봇: **교실 1대 교사 시연**(기본안) / 모둠당 1대
3. 대학 대상은 STEP 1을 건너뛰고 STEP 2부터 시작해도 될지
4. 미션 8개의 순서 · 주제 중 바꾸고 싶은 것 (예: 그림 그리기 미션을 앞쪽으로)
