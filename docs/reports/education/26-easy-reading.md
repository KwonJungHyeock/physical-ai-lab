| 요청 | 결정 |
| --- | --- |
| 단어가 중간에 끊기고 줄바꿈 위치가 들쭉날쭉함 | 단어 단위로만 줄바꿈 (한글 `keep-all`), 한 문장은 한 줄에, 문장마다 줄을 바꿈 |

## 2. 글 읽기

- 화면 전체: 단어 가운데서 줄을 바꾸지 않음. 문단은 끝줄에 한두 글자만 남지 않게 맞춤 (`text-wrap: pretty`).
- 수업 · 현장 실습 패널: 한 문장 = 한 줄. 문장이 끝나면 줄을 바꿈.
- 원고: 긴 문장은 두세 문장으로 나눔. 괄호 속 덧붙임 · 수식 설명은 이론서로 옮김.
- 기호의 이름표(μ 위의 '마찰 계수' 같은 작은 글)는 줄 폭을 차지하므로, 이름표까지 넣어 한 줄에 들어가게 씀.
- 현장 실습: 학습 목표, 담당자 말, 지금 작업 프로그램, 예상 결과, 다시 고치기 안내를 문장(값)마다 한 줄로.
- 평가: 난이도 표시(기본 · 응용 · 대학)를 문제 위 작은 줄로 옮겨, 문제가 한 줄 폭을 다 씀.

| 측정 (1366 × 768, 패널 한 줄 ≈ 22 em) | 전 | 후 |
| --- | --- | --- |
| 한 줄에 들어가는 문장 (28차시 · 현장 · 실습 7, 문항 제외) | 65 % | 100 % (4 683 문장) |
| 세 줄 이상 되는 문장 | 172 | 0 |
| 확인 문항 (문제 · 보기 · 풀이) | 두 줄 허용 | 모두 한 줄 계산 |

측정 도구: `npx tsx tools/check/text-fit.mts` (원고에서 계산, 기호 이름표 폭 포함),
`node tools/check/text-lines.mjs` (앱을 띄워 실제로 그려진 줄 수, 28차시 × 7쪽 + 현장 7곳 × 3문제 × 6단계).

## 3. 수업 흐름

| 전 | 후 |
| --- | --- |
| 결과를 보지 않아도 [다음] 으로 넘어감 | 활동은 결과가 나와야, 평가는 확인 문제를 다 맞혀야 다음이 열림 ("해 보고 결과를 보면 열려요") |
| 교사가 시연할 때도 막힘 | 교사 계정 · 교사용 보기에서만 [건너뛰기 (교사용)] |
| 지나간 단계에 모두 ✓ | ✓ 는 결과를 본 활동, 맞힌 평가에만 |
| 다음 차시 버튼이 앞 차시로 보낼 때가 있음 | 지도에서 다음 할 일이 지금보다 앞 차시면, 순서상 다음 차시로 |
| 수업 안 활동 탭 + 아래 [다음] (같은 이동 두 개) | 아래 [다음] 하나 |
| 현장 실습 단계 표시가 위 · 패널 두 곳 | 위 단계 막대 하나 |
| 현장 적용 카드가 늘 펼쳐짐 | 현장마다 처음 한 번만 펼침 |

## 4. 이론서 안내

- 개념 쪽: "더 깊이 알고 싶다면 · 📘 N단원 이론서 PDF · ○쪽" — 누르면 그 단원 PDF 가 그 차시 쪽에서 열림.
- 활동의 '왜 그럴까?' 아래에도 같은 링크(작게).
- 쪽 번호는 PDF 에서 읽어 만듦: `npm run gen:theory-pages` (`src/engine/education/theoryPages.gen.ts`, 28차시).
- 원고가 바뀌면 이론서 PDF 를 다시 만들고(`node tools/build/materials.mjs`) 쪽 번호도 다시 만듦.
