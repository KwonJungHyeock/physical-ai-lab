# 보고 #33 — 수업 화면 공통 양식 · 1·2단원 검증 반영 배포

작성: 2026-10-14

보고 #32 의 1·2단원 검증 결과를 원고에 반영했습니다(자세한 것은 `32-review-u12-result.md`).
그 뒤 수업 화면 왼쪽 레일을 시뮬레이션 챕터 공통 양식(미션 · 지금 할 일 · 고정 색)에 맞췄습니다.

## 1. 수업 레일

| 자리 | 전 | 후 |
| --- | --- | --- |
| 맨 위 | 차시 제목 줄, 도입에만 "오늘의 질문" | 어두운 **미션 카드**: 오늘의 질문 + 활동 1 · 2 · 3 목표(지금 = 파랑, 끝냄 = ✓) + [교사용] |
| 그 아래 | 없음 | 초록 **지금 할 일** 띠: 동사로 끝나는 한 문장, 단계 · 시간 |
| 눌러야 할 곳 | 표시 없음 | 예상 → 해 보기 → [다음] 차례로 초록 반짝임 (움직임 줄이기 설정이면 멈춤) |
| 블록 색 | 개념 흰색 · 질문 주황 · 해 보기 파랑 | 개념 파랑 · 질문 회색 · 해 보기 흰색 · 결과 초록 · 교사용 점선 |

지금 할 일 문장은 화면 상태에서 정해집니다.

| 상태 | 문장 |
| --- | --- |
| 도입 | 그림을 보고 오늘 배울 것을 읽어요. |
| 개념 | 핵심 한 줄과 원리를 읽어요. |
| 활동, 예상 전 | 예상을 하나 골라요. |
| 활동, 결과 전 | 해 보기의 할 일대로 직접 움직여 봐요. |
| 활동, 결과 뒤 | 결과와 이유를 읽고 다음으로 가요. |
| 정리 | 세 활동의 결과를 비교해 읽어요. |
| 평가 | 확인 문제를 모두 풀어요. → 다 맞히면 다음 차시로 넘어가요. |

함께 고친 것:

- 목표 이름이 긴 차시(8-2 "블록 1개 · 정해진 자리" 등)도 칸 안에서 줄을 바꿔 잘리지 않습니다.
- 실물 연동 막대를 한 줄로 줄이고 3D 화면 왼쪽 아래로 옮겼습니다. 오른쪽 아래 조작 안내와 겹치지 않습니다.
- 교사 가이드의 레일 설명 · 블록 색을 고치고, 수업 화면 그림 7장을 다시 찍었습니다.

넣지 않은 것: 장면 속 주황 "관찰" 말풍선, 화면 맨 아래 "출처 · 임시" 줄.
차시마다 계산 결과를 이어야 하고 시뮬레이터 화면이 바뀌므로, 검증 지시서 범위(시뮬레이터 동작 · 비주얼 변경 제외) 밖으로 두었습니다.

확인: 1366×768 에서 2-2 다섯 페이지 · 8-2 · 3-2(교사용) 화면, 타입 검사 · eslint · `npm run check` 통과, 매뉴얼 PDF 세 권 두 줄 넘는 문장 0.

## 3. 배포 (GitHub `release` 브랜치)

시험판은 GitHub `release` 브랜치에서 바로 받습니다. 파일은 두 개입니다.

| 파일 | 무엇 | 크기 |
| --- | --- | --- |
| `PhysicalAI-Simulator.zip` | 시뮬레이터 프로그램 (Windows) · 교사용 학급 서버 · 읽어보세요 | 91 MB |
| `eduino_usb.zip` | 로봇 USB 키트 (키트 `20261015-020356-9bfd666`) | 85 MB |

GitHub 는 100 MB 넘는 파일을 받지 않아서 두 가지를 바꿨습니다.

- 로봇 키트에서 설명서 PDF 세 권(약 17 MB)을 뺐습니다. PC 프로그램 자료실에는 그대로 있습니다.
  로봇 화면에서 설명서를 누르면 "PC 프로그램 → 자료실에서 열어 주세요" 안내가 나옵니다.
- 시뮬레이터에 키트를 넣지 않고, 옆에 둔 `eduino_usb.zip`(exe 폴더 또는 그 위 폴더)을 찾아 로봇 USB 만들기에 씁니다.

확인한 것: 받은 그대로의 폴더 구조에서 프로그램이 옆의 키트를 찾음(Linux 로 같은 프로그램을 띄워 확인), 처음 화면 · 시뮬레이터 · 수업 · USB 만들기 창, Go 테스트 · USB 점검, 두 zip 검사.
남은 것: 실제 Windows PC 에서 한 번 실행해 보기.

## 4. 디자인 원칙 점검 (frontend-design)

일반 화면 디자인 원칙(템플릿처럼 보이는 습관 피하기)으로 레일을 다시 보고 고쳤습니다.

| 원칙 | 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| 쓸데없는 라벨을 내용 위에 달지 않는다 | 미션 카드 위 "2-2 역기구학 · 오늘의 질문" (바로 위 머리줄에 차시 이름이 이미 있음) | "오늘의 질문" |
| 같은 말을 두 번 쓰지 않는다 | 블록 머리 "결과 결과", "해 보기 · 직접 움직여요 해 보기", "질문 · 골라요 예상" | "결과", "해 보기", "질문 예상" (할 일은 '지금 할 일' 띠가 말함) |
| 버튼 글에 화살표(→)를 붙이지 않는다 | [← 개념] [활동 2 · 반복 풀이 →] | 왼쪽 [이전 / 개념], 오른쪽 [다음 / 활동 2 · 반복 풀이] |
| 저절로 움직이는 효과는 한 번, 주의를 끌 때만 | 눌러야 할 곳이 끝없이 반짝임 | 새로 생길 때 세 번 반짝인 뒤 초록 테두리로 멈춤 |
| 강조는 한 곳에 | 파란 다음 버튼 아래 파란 그림자 | 그림자 없앰 (어두운 미션 카드가 레일의 한 가지 강조) |

그대로 둔 것: 가운뎃점(A · B)은 이 프로젝트 글 전체의 표기법이라 유지했습니다.
