## 1. 수업 레일

| 자리 | 전 | 후 |
| --- | --- | --- |
| 맨 위 | 차시 제목 줄, 도입에만 "오늘의 질문" | 어두운 **미션 카드**: 오늘의 질문 + 활동 1 · 2 · 3 목표(지금 = 파랑, 끝냄 = ✓) + [교사용] |
| 그 아래 | 없음 | 초록 **지금 할 일** 띠: 동사로 끝나는 한 문장, 단계 · 시간 |

| 블록 색 | 개념 흰색 · 질문 주황 · 해 보기 파랑 | 개념 파랑 · 질문 회색 · 해 보기 흰색 · 결과 초록 · 교사용 점선 |

지금 할 일 문장은 화면 상태에서 정해집니다.

| 상태 | 문장 |
| --- | --- |
| 도입 | 그림을 보고 오늘 배울 것을 읽어요. |
| 개념 | 핵심 한 줄과 원리를 읽어요. |
| 활동, 예상 전 | 예상을 하나 골라요. |
| 활동, 결과 전 | 해 보기의 할 일대로 직접 움직여 봐요. |
| 활동, 결과 뒤 | 결과와 이유를 읽고 다음으로 가요. |
| 정리 | 세 활동의 결과를 비교해 읽어요. |
| 평가 | 확인 문제를 모두 풀어요. → 다 맞히면 다음 차시로 넘어가요. |

함께 고친 것:

- 목표 이름이 긴 차시(8-2 "블록 1개 · 정해진 자리" 등)도 칸 안에서 줄을 바꿔 잘리지 않습니다.
- 실물 연동 막대를 한 줄로 줄이고 3D 화면 왼쪽 아래로 옮겼습니다. 오른쪽 아래 조작 안내와 겹치지 않습니다.
- 교사 가이드의 레일 설명 · 블록 색을 고치고, 수업 화면 그림 7장을 다시 찍었습니다.

넣지 않은 것: 장면 속 주황 "관찰" 말풍선, 화면 맨 아래 "출처 · 임시" 줄.
차시마다 계산 결과를 이어야 하고 시뮬레이터 화면이 바뀌므로, 검증 지시서 범위(시뮬레이터 동작 · 비주얼 변경 제외) 밖으로 두었습니다.

확인: 1366×768 에서 2-2 다섯 페이지 · 8-2 · 3-2(교사용) 화면, 타입 검사 · eslint · `npm run check` 통과, 매뉴얼 PDF 세 권 두 줄 넘는 문장 0.
