# 보고 #24 — 수업 화면 개편 · 3D 수업 그림 · 학급 계정 화면, 실물 연동 시험 준비

작성: 2026-10-11 · 시뮬레이터 묶음 delivery24

## 1. 요청과 결정

| 요청 | 결정 |
| --- | --- |
| 이론 · 고르는 버튼 · 문제가 모두 흰색이라 구분이 안 되고, 순서대로 가기 불편 | 수업을 왼쪽 한 줄(레일)로 모으고, 블록 종류마다 색 · 아이콘 · 이름표를 다르게 |
| 평가 뒤 다음 차시로 가는 표시가 없음 | 맨 아래 큰 버튼이 갈 곳 이름을 말함, 마지막엔 초록 '다음 차시 / 현장' |
| 배경은 밝게, 디테일 · 영역 구분 · 임팩트 | 밝은 스튜디오 기본, '오늘의 질문' · 그림은 어두운 틀 |
| 우리 3D 모델로 수업 그림 | 활동 끝 화면 75장(25차시), 정리 화면에서 세 활동 비교 |
| 관리자 / 학생 나누기, 학습 데이터 | 교사 PC 학급 서버 + 가명 클라우드 (보고 #23), 화면 연결 |

## 2. 수업 화면 (왼쪽 레일)

| 색 | 이름표 | 무엇 |
| --- | --- | --- |
| 흰색 | 개념 | 읽는 것: 핵심 한 줄, 원리, 왜 그럴까 |
| 주황 | 질문 · 골라요 | 고르는 것: 동그라미 보기 (버튼 모양이 아님) |
| 파랑 | 해 보기 · 직접 움직여요 | 차시의 조작 (슬라이더 · 버튼 · 그래프) |
| 초록 | 결과 | 나온 값과 예상이 맞았는지 |
| 회색 점선 | 교사용 | 발문 · 정답 (교사용 보기를 켤 때만, 학생 로그인에선 숨김) |

- 활동은 ① 예상 → ② 해 보기 → ③ 결과 → ④ 왜 순서. 지금 할 칸만 테두리, 다음 칸은 접혀 기다림.
- 예상을 고르면 조작이 열리고 그 자리로 스크롤, 결과가 나오면 결과 칸으로 스크롤.
- 3D 수업 그림은 정리 화면에만 (활동 전에 보이면 예상을 하기 전에 답이 보임).
  4-2 · 5-3 · 7-2 는 3D 끝 화면에 차이가 없어 그림(일러스트) 그대로.

## 3. 학급 계정 (화면)

- 학급 서버가 없으면 지금과 같음 (관리자 · 시연: 모든 기능 열림).
- 학급 서버(`교사용 학급 서버.cmd`)가 있으면: 학생은 학급 코드 + 번호 + PIN, 선생님은 아이디 + 비밀번호.
- 선생님: 학급 관리 — 실시간 현황(어디서 무엇을 · 막힘 · 쉬는 중 · 오프라인 · 잠김), 학생 발급과 로그인 카드 인쇄,
  차시 열기, 이름표(이 PC 에만), CSV.
- 한 PC 를 여러 학생이 쓸 때: 로그인한 학생의 진도만 보임 (로그아웃하면 PC 의 진도로 돌아옴).
- 학생에겐 '반 결과' · '교사용 기록 지우기' · '제출하고 다음 학생' 이 보이지 않음.

## 4. 이번에 고친 것

- 1-4 활동 2 세로 단면이 팔 평면과 45° 어긋남: 팔이 몸통 축에서 약 65 mm 옆에 있는데, '앞' 방향을 접힌
  홈 자세 손끝의 방위로 잡아서 생긴 오차. J2 를 돌릴 때 손끝이 움직이는 방향으로 바꿈 (0° 로 맞음).
- 현장 실습 재생: 프레임이 없는 실행에서 매 프레임 오류가 나던 것 막음.

## 5. 확인한 것 (이 환경)

- `npm run check` 전체, `npx tsc`, eslint, `go vet` · `go test` 통과.
- 화면 점검 `learn-ui` (1-1 · 1-4 · 3-2), 실습 대조 `learn-sim` (1-1 · 1-2 · 1-4) 통과 — 1-1 · 1-4 는 빌드한 프로그램으로도 확인.
- 실물 연동: 가짜 로봇 서버로 수업 1-1 에서 켜기 → 목표 1회 12° 이내 · 속도 50 이하로 따라감,
  현장 실습은 [다시 가동 · 비교] 에서만 따라감, Esc 로 멈춤.
- 학급 계정: 실제 학급 서버로 설정 → 학급 → 발급 → 학생 로그인 → 잠금 → 끊김 대기열 → 교사 현황.
- 실제 로봇 · 실제 Windows 에서는 아직 확인하지 않음.

## 6. 내일 실물 연동 시험 순서 (제안)

로봇 프로그램(로봇 쪽)은 바꾼 것이 없어 USB 업데이트는 필요 없음. PC 에서 delivery24 의 시뮬레이터만 새로 풀기.

1. 로봇 전원 · 같은 공유기 → 시뮬레이터 실행 → 오른쪽 위 [로봇 연결].
2. 교육 → 1-1 관절 · 링크 · 자유도 → 활동 1. 팔 둘레를 비우고 아래 [실물 연동] 켜기.
3. 예상을 고르고 [J1 끝에서 끝까지] → 실물이 화면을 따라 도는지, 화면과 차이(°)가 작게 유지되는지.
4. 아무 때나 Esc 또는 [■ 실물 멈춤] 으로 바로 서는지.
5. 1-4 활동 2 (J2 · J3 슬라이더), 2-1 / 2-3 처럼 팔이 크게 움직이는 차시도 한 번씩.
6. 현장 실습(물류 등): 값을 고친 뒤 [다시 가동 · 비교] 에서만 따라가는지.
7. 이상하면 화면 아래 막대의 글(멈춘 이유)과 함께 알려 주세요.
