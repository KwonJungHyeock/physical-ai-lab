# 보고 #20 — 통합 월드맵: 로봇공학 이론과 현장 테마 학습을 섬 도시 하나로

## 1. 요약

- 교육 홈을 **섬 도시 하나**로 바꿉니다. 가운데 블록은 **로봇 아카데미**(기존 8학문 28차시 이론)이고, 둘레 여덟 블록은 로봇이 실제로 쓰이는 **현장 테마**입니다.
- 테마 블록을 누르면 그 현장을 그린 환경으로 들어가, **myCobot 280 RDK X5** 로 그 현장의 사회 문제·공정·효율 과제를 풉니다.
  기존 실습 6곳(공장·물류·바이오·스마트팜·카페·AI 연구소)은 해당 테마의 첫 콘텐츠로 그대로 씁니다.
- **디지털 트윈 관제센터** 블록은 데이터 사이언스를 맡습니다. 모든 테마 실습의 기록(사이클 타임, 성공률 등)을 모아 비교하고, 로봇을 연결했을 때는 실측값과 시뮬레이션 값을 나란히 봅니다.
- 모델링은 외부 CC0 자산(KayKit, Kenney, Quaternius)으로 다시 했습니다. 시안 화면은 `/spike/world` 이고, 아직 교육 탭에 연결하지 않았습니다(결정 후 연결).

## 2. 지도 구조 — 장소 세 종류

| 종류 | 블록 | 하는 일 |
| --- | --- | --- |
| **이론** | 로봇 아카데미 (가운데) | 8학문 28차시. 광장의 8개 학문관이 8학문이고, 가운데 myCobot 280 상이 시작점입니다. |
| **테마** | 둘레 7곳 | 현장의 문제를 로봇으로 풉니다. 문제마다 관련 학문 차시로 링크합니다. |
| **데이터** | 디지털 트윈 관제센터 | 실습 기록 분석(데이터 사이언스)과 실물↔시뮬 비교(디지털 트윈)를 합니다. |

이론과 테마는 서로 링크합니다. 테마 문제 카드에는 "이 원리는 ○학문 ○차시"를, 차시의 '현장에서는' 칸에는 "이 원리가 쓰이는 테마"를 넣습니다.
그래서 이론 → 현장, 현장 → 이론 어느 쪽으로도 들어갈 수 있습니다.

## 4. 누르면 어떻게 되나

1. 지도: 섬 전체. 블록마다 핀이 있습니다(이론 / 테마 / 데이터).
2. 블록 하나를 누르면 카메라가 그 블록으로 날아가고, 오른쪽 카드에 **사회 문제 한 줄 → 이 현장의 로봇 → 문제 3개(관련 학문) → [들어가기]** 를 보여 줍니다.
3. [들어가기] 를 누르면 그 테마의 현장 환경(기존 실습 화면 형식: 장면 + 6단계 패널)으로 들어갑니다.
4. 실습 결과는 자동으로 관제센터에 쌓입니다. 관제센터에서는 테마별 기록을 비교합니다. 로봇이 연결되어 있으면 실측값도 함께 비교합니다.

잠금 규칙은 지금처럼 둡니다. 아카데미 1학문을 마치면 테마가 열리고, 교사는 '모든 현장 열기'로 한 번에 열 수 있습니다.

## 5. 데이터 사이언스 · 디지털 트윈

- **기록**: 실습을 한 번 돌릴 때마다 시각, 테마, 문제, 바꾼 값, 결과(성공 여부, 걸린 시간, 오차 mm)를 브라우저에 저장합니다. 기존 해결 기록 저장 방식을 넓힙니다.
- **분석 활동**(관제센터):
  - 같은 문제에서 바꾼 값과 결과의 관계를 산점도로 봅니다(예: 속도 ↔ 실패율).
  - 테마별 사이클 타임을 비교하고 병목을 찾습니다.
  - 반복 측정의 평균과 표준편차를 구합니다.
- **디지털 트윈**: 로봇이 연결되어 있으면 같은 프로그램을 시뮬과 실물에서 돌리고, 관절 각도 기록의 차이를 그래프로 비교합니다.
  기존 콘솔의 실시간 상태(`/api/state`)를 그대로 씁니다.

## 7. 시안에서 된 것 / 아직인 것

- **된 것**
  - 섬, 9블록, 도로망, 차량, 숲, 항구, 풍력, 연못
  - 블록마다 myCobot 280. 실제 URDF 모델이 천천히 움직입니다.
  - 조명(그림자, AO, 톤매핑, 블룸), 블록 핀
  - 개발 화면 `/spike/world`. `?cam=x,y,z&at=x,y,z` 로 시점을 바꿉니다.
- **확인한 방법**
  - 타입 검사를 통과했습니다.
  - 헤드리스 브라우저(소프트웨어 렌더링)로 전체와 블록 근접 화면을 캡처해 눈으로 확인했습니다.
  - 온실 유리가 AO 패스를 깨뜨려 화면이 검게 되는 문제를 찾아 고쳤습니다(유리도 깊이를 기록).
  - 실제 GPU(교실 PC)에서의 프레임 수는 아직 재지 않았습니다.
- **아직**
  - 교육 탭 연결, 클릭 → 카메라 이동 → 카드, 잠금 표시
  - 에너지·관제센터 새 콘텐츠
  - 차량 이동 애니메이션
  - exe 반영

## 8. 결정 후 순서

1. 지도를 교육 홈에 연결합니다(기존 산업단지 지도 교체). 클릭, 카드, 잠금, 진행 표시를 넣고, 기존 6개 실습과 아카데미 차시를 링크합니다.
2. 이론↔테마 상호 링크(문제 카드의 학문 차시, 차시의 '현장에서는')를 넣습니다.
3. 실습 기록 저장을 넓히고, 관제센터 화면(그래프, 비교, 실물↔시뮬)을 만듭니다.
4. 에너지·자원순환 테마(재활용 선별 3문제)를 만듭니다.
5. 스마트시티 돌봄 보조 문제를 추가합니다.
6. 성능 점검(교실 PC), exe 재빌드, 매뉴얼을 반영합니다.
