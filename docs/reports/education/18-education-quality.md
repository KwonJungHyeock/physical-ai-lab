## 2. 실습교육서 양식

- **화면 교육자료**: 쪽마다 머리글(주제 · 쪽 번호) → Q 상자 → 그림(번호 · 캡션 · 기호 줄, ↻ 다시 보기 · ⤢ 크게) → 정의 · 원리 상자 →
  기호 표 · 용어. 실습 쪽은 실습지 머리(A · B · C 진행, **▶ 시연 보기**) → 할 일 · 볼 것 → **기록표**(시뮬레이터가 채움).
  비교 쪽은 비교하기 · 비교할 값 칩 · 그림 · 비교표 · 기억할 것.
- **자료실 이론 PDF**: 학문 표지(번호 · 목표 · 선수 · 주제 목차 · 쓰는 법) → 주제마다 머리 띠 · Q · 그림과 캡션 · 정의 · 원리 · 기호 표 ·
  자세히 · 수식 → **실습지**(A · B · C 할 일 · 볼 것 + 손으로 적는 **빈 기록표** + "알게 된 것" 줄) → 기억할 것 · 용어.
  문항지도 기호를 같은 글꼴로, 주제 제목 옆에 그 주제 기호 이름을.

## 4. 28주제 검수

### 방법
학문별로 원고 · 그림 · 실습 화면 코드를 함께 읽고 흐름(질문 → 정의 → 원리 → 자세히 → A → B → C → 비교 → 기억할 것, A·B·C 는 한 가지씩만
바뀌는지) · 적합성(로봇공학적으로 맞는지, 수준) · 숫자 일관성(원고 · 그림 · 화면 · 문항)을 봤습니다.
그리고 **시뮬레이션 자동 대조**(`web-typescript/tests/education/sim/`, `tools/check/learn-sim.mjs`)를 만들어, 브라우저가 실습 A·B·C 를 원고의 할 일대로 누르고
결과 칩이 볼 것의 숫자와 같은지 확인합니다 — **84 실습 모두 일치**(결과는 §6).

### 고친 것 (화면 버그)
- 실습을 바꿀 때 늦게 도는 초기화가 막 시작한 실행을 취소해 결과가 안 나오던 것 (5-x 관절 모델, 6-3, 6-4, 8-2)
- 3-1: 화면이 느리면 짧은 누름 · 움직임이 사라지던 것 → 실제 경과 시간 기준
- 1-2: 결과 칩이 실제 손끝 대신 목표 숫자를 그대로 적던 것 → 실제 손끝(역기구학 허용 0.3 mm)
- 1-4: 원 길이를 화면 프레임으로 재 느린 PC 에서 짧게 나오던 것 → 1° 간격 계산(늘 1407 mm)
- 4-1: 수평 거리를 J2 축 방향 어긋남까지 더해 셌던 것 → 247 / 280 mm (토크와 일치)
- 6-2 B: 경유점 높이 240 mm 에서는 손이 벽 위에 닿지 않아 경유점을 찍을 수 없었음 → 220 mm
- 1-1 C: 같은 점 다른 자세가 2개만 나오던 것 → 3개

### 고친 것 (원고)
- 1-1 정의 "움직이지 않는 막대" → "모양이 변하지 않는 단단한 막대" (자세히와 모순)
- 1-3 피치 0° 기준이 1-2 와 다름을 명시 · 3-2 "몇 mm" → 약 9 mm · 3-3 12 → 12.7 m/s² (근거 계산 포함) · 5-4 누르는 힘 8.3 · 3.5 · 0.6 N ·
  6-3 `v` = √(2`g``h`) · 7-3 지연과 이득 한계를 자세히에 먼저 · 볼 것에 화면이 내는 숫자를 빠짐없이
- 문항 해설을 다시 계산해 확인(정답 바뀐 곳 없음), 대학 문항의 첨자 기호(x₁, fₓ …)는 말로 풀어 씀
- `- 그림:` 줄을 실제 그림에 맞춤(학문 2~8)

### 흐름: 2-3 다시 구성
C 가 "자세 유지" 가 아니라 "펜 · 사각형" 으로 바뀌어 한 가지만 바꾸는 원칙에서 벗어났습니다. 요청서 구성대로 **같은 펜 · 같은 A → B** 를

| 실습 | 자취 길이 | 직선에서 벗어남 | 펜 기울기 |
| --- | --- | --- | --- |
| A 관절 이동 (MOVJ) | 253 mm | 35.5 mm | 0° |
| B 직선 이동 (MOVL, 위치만) | 240 mm | 0.6 mm | 12.6° |
| C 직선 + 자세 유지 | 240 mm | 0.8 mm | 0° |

로 바꿨습니다(원고 · 그림 · 화면 · 문항 · 대조 함께). 기억할 것: "관절이 고르게 돌면 손끝은 휘고, 손끝 위치만 곧게 가면 도구가 기운다".
