# 보고 #49 — 1단계 12차시: 서브챕터별 장면 범위 · 전개 · 교안 매칭

[보고 #48](48-track-life-basic-calligraphy.md)의 6장 · 29개 서브챕터 · 12차시를 앱 장면과 PDF 교안에 맞춘 확정안입니다. 근거: 로봇 시뮬레이터 지시서 v1(PDF 수업자료 동행 구조) · 설계화면 · 벤치마킹 보고서(2026-11).

## 확정한 것 (2026-11-10)

1. 입문 트랙(`/track/life`)은 이 12차시로 교체합니다. 카페 · 보드게임 현장과 4 · 6 · 8차시는 입문에서 숨기고 코드는 보관합니다. 전체 버전(`/console`)은 그대로입니다.
2. 1장(이론)도 짧은 체험 장면을 둡니다(손이 다가가면 멈춤 · 관절 찾기 · 정지 누르기). 개념 글은 교안이 맡습니다.
3. 4장 도형 · 원 · 별은 꼭짓점 좌표 표로 넣습니다(숫자 입력 + 매트에 점 미리보기). 실물 로봇에 같은 값을 보냅니다.

## 원칙

- 서브챕터 버튼 하나 = 장면 하나 = 교안 2쪽(할 일 + 화면 예시 / 이렇게 되면 성공). 번호(3-2)는 교안 장 · 절 번호와 같습니다.
- 모든 서브챕터는 같은 5칸으로 진행: ① 교안 쪽(교사가 PDF를 띄우고 학생은 위치 줄에서 같은 번호 확인) → ② 지금 할 일(한 줄 + 누를 곳 번호) → ③ 해 보기(조작 · ▶ 실행, 결과는 장면에서) → ④ 결과 확인(자동 체크) → ⑤ 다음(학생이 누름, 자동 넘김 없음).
- 챕터 끝 수행평가: O · X 5문항(문제는 교안, 앱은 번호와 O · X만) + 미션 1개(장면에서 자동 채점) → 상 · 중 · 하. 상 = O · X 5 + 미션 통과 / 중 = 하나 놓침 / 하 = 둘 이상.
- 한 차시 50분: 도입 5분(교안 표지) → 서브챕터 2 ~ 3개 × 12 ~ 15분 → 정리 5분(기록 저장).
- 위치 줄: `5차시 · 3-4 내 자세 저장 · 교안 34~35쪽`. 목록은 차시 → 장 → 서브챕터, 건너뛴 것은 미완료.
- 장면은 한 무대 위에서 카메라 · 소품만 바꾸는 6종: A 실습대 전체 · B 책상과 구성품 · C 로봇 근접(관절) · D 매트 위에서(궤적) · E 펜 끝 · 카드 근접 · F 사진 · 기록 화면(3D 없음). 다음 단계 재모델링의 범위입니다.

## 만드는 순서

1. 구조 데이터: 장 · 서브챕터 · 차시 · 교안 쪽 · 장면 · 체크를 한 표로(위치 줄 · 목록 · 학습 기록이 이것을 읽음).
2. 있음 · 고침 18개: 기존 장면에 체크와 번호를 붙임(5장 · 4-1 · 3-4부터).
3. 새로 11개 + 수행평가 틀: 관절 표지 · 목표 각도 · 목표 자세 고스트 · 도형 · 원 · 별 · 획 입력 · 후기.
4. 재모델링: 장면 6종을 한 무대로. 콘셉은 구조를 만든 뒤 따로 제안.
