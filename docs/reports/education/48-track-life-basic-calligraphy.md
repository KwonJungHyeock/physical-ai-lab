# 보고 #48 — 가오픈 커리큘럼 확정: myCobot 기초조작 + 캘리그라피 (12차시)

보고 #47(세 현장 10차시)을 대신합니다. 가오픈 키트에서 myCobot 시뮬레이터는 세 현장 중 **캘리그라피 하나**로 줄이고,
**기초조작 + 캘리그라피** 버전으로 냅니다. 12월 현장 실증(고등 대상)도 이 범위로 합니다.

- 대상: 고등학생 · 12차시 · 차시당 50분
- 흐름: 협동로봇 이론 → 로봇 준비(연결 · 수업 세팅) → 관절 제어 → 좌표와 궤적선 그리기 → 캘리그라피(시뮬레이션 → 실물) → 학습 기록 · 후기 · PDF
- 수행평가: 1~5장 끝마다 O·X 5문항(자동 채점) + 미션 1개. 상 = O·X 5개 + 미션 통과 / 중 = 하나 놓침 / 하 = 둘 이상 놓침
- 마지막: 챕터별 평가 결과 확인 → 수업 후기 → 학습 기록 PDF 저장으로 과정이 끝납니다.

## 챕터 · 서브챕터

### 1. 협동로봇과 만나기 (1차시)
- 1-1. 협동로봇이란?
- 1-2. 로봇팔의 구조: 관절 · 좌표 · 도구
- 1-3. 안전하게 쓰기
- 1-4. [수행평가] O·X + 미션 — 미션: 사진 속 로봇 중 협동로봇 고르기

### 2. 로봇 준비하기: 연결과 수업 세팅 (2차시)
- 2-1. 구성품과 작업대 놓기
- 2-2. PC에 시뮬레이터 설치 · 로봇 연결
- 2-3. 영점과 기본 자세 확인
- 2-4. 펜 끼우고 높이 맞추기
- 2-5. [수행평가] O·X + 미션 — 미션: 수업 준비 체크리스트 완성(연결 → 영점 → 기본 자세 → 펜 높이)

### 3. 기초 제어 ① 관절 제어 (2차시)
- 3-1. 관절 6개 알아보기: J1 ~ J6의 이름과 역할
- 3-2. 관절 하나씩 움직이기: 각도와 방향(+ / −)
- 3-3. 관절이 움직일 수 있는 범위와 한계
- 3-4. 기본 자세 · 영점 자세와 내 자세 저장
- 3-5. 속도 조절과 멈추기
- 3-6. [수행평가] O·X + 미션 — 미션: 제시된 목표 자세(관절 각도)를 관절 조그로 똑같이 만들기

### 4. 기초 제어 ② 좌표와 궤적선 그리기 (3차시)
- 4-1. 좌표로 움직이기: X · Y · Z와 손끝
- 4-2. 궤적선 켜고 선 긋기: 직선 이동 vs 관절 이동
- 4-3. 도형 그리기: 삼각형 · 사각형
- 4-4. 곡선과 원 그리기
- 4-5. [수행평가] O·X + 미션 — 미션: 별 모양을 한 번에 그리기

### 5. 로봇 캘리그라피: 시뮬레이션 → 실물 (4차시)
- 5-1. 캘리그라피 로봇 사이클 보기
- 5-2. 카드 위치 · 펜 높이 보정
- 5-3. 획 나누기: 펜 들고 옮기기
- 5-4. 내 글자 쓰기 (시뮬레이션)
- 5-5. 실물로 쓰기
- 5-6. [수행평가] O·X + 미션 — 미션: 실제 로봇으로 메시지 카드 한 장 완성

### 6. 마무리: 학습 기록과 수업 후기 (12차시 뒷부분)
- 6-1. 챕터별 평가 결과 확인
- 6-2. 수업 후기 쓰기 — 가장 재미있었던 활동 · 어려웠던 점과 해결 · 실물과 시뮬레이션의 차이 · 더 해 보고 싶은 것 · 자기 평가(별 5개)
- 6-3. 학습 기록 PDF로 저장하기 — 이름 · 반 · 날짜, 챕터별 평가, 후기를 한 장으로

## 앱에 있는 것과 새로 만들 것

- 있음: 관절 · 좌표 조그, 자세 저장 · 기본 자세 · 영점 자세, 영점 맞추기, 도구 바꾸기, 표시 옵션의 '도구 궤적', 로봇 연결(Wi-Fi · 랜선 직결),
  로봇 설치 도구(USB 키트 · LAN 설치), 기초 튜토리얼(팔 움직이기 · 자세 · 위치 가르치기 · 고리 통과), 캘리그라피 G1 ~ G4, 잠깐! 퀴즈 모달,
  학습 기록 패널과 기록지 PDF · 제출 파일, 교사 열쇠.
- 새로 만들 것: 챕터 · 서브챕터 내비와 번호 체계, 1장 개념 카드, 2장 준비 화면(배치도 · 체크리스트 · 펜 높이), 3장 관절 실습과 목표 자세 미션,
  4장 도형 · 원 그리기와 별 미션, 5장 내 글자 쓰기와 실물 실행 흐름, 챕터별 O·X 평가 틀, 6장 후기 입력과 한 장 PDF.

## 남은 결정

1. 실증 로봇과 연결 방식: myCobot 280 RDK X5 + Wi-Fi(로봇 설치 도구 · USB 키트) 또는 USB 직접 연결(Web Serial).
2. 펜 장착 방식: 펜 홀더 부품 또는 그리퍼로 잡기.
