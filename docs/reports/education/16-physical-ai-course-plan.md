■ 4. 대표 차시 상세 (먼저 만들 3개)
 [2-3 움직임의 질 — 위치 → 속도 → 가속도]
  과제: 흡착 없이 손끝 판 위에 블록을 올리고 A 지점 → B 지점 나르기 (물리엔진: 마찰만으로 블록이 붙어 있음)
  A 위치만: 목표 각도를 한 번에 보냄 → 서보가 최대 속도로 튀어 감, 출발·도착에서 블록이 미끄러져 떨어짐
  B 위치+속도: 일정 속도로 이동 → 중간은 부드럽지만 출발·정지 순간 덜컥(가속도가 순간적으로 매우 큼) → 블록이 밀림
  C 위치+속도+가속도: 가속도를 제한(사다리꼴), 더 나아가 가가속도까지(S자) → 블록이 끝까지 붙어 있음
  비교: 세 방식 겹쳐 재생, 위치·속도·가속도 그래프 3단 겹침, 표(걸린 시간 / 최대 가속도 / 블록 떨어짐 여부)
  실물: 로봇 속도 설정(1~100)이 어떤 방식인지 생각해 보기, 같은 거리 3가지 속도로 실물 이동 시간 재기
 [1-2 위치와 좌표]
  A: 책상 격자에서 손끝의 x·y 를 읽고 목표 칸으로 이동 / B: 높이 z 를 더해 블록 위로 / C: 같은 위치에서 손끝 방향만 바꾸기
  확인: "같은 위치라도 자세가 다르면 다른 동작이다" 등 OX
 [3-3 제어 — 개루프 → P → PID]
  모델: 관절 하나(질량·중력·모터 힘 한계), 목표 각도 0° → 60°
  A 명령만: 정해진 힘을 정해진 시간만 → 무게가 바뀌면 다른 곳에 섬 / B P: 넘쳤다 돌아오거나 조금 모자라게 섬(남는 오차)
  C PID: 남는 오차 없이, 흔들림 적게. 게인 슬라이더 3개, 응답 그래프(목표선·넘침·자리 잡는 시간)
  실물: 로봇 서보 안에서도 이 제어가 돌고 있음 — 무게를 달면 각도가 얼마나 처지는지 실물로 재기
