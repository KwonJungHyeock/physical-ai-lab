# 보고 #35 — 가변저항 티칭 팔로 모방학습: 시험용 기획

정규 교육과는 다른 갈래로 둡니다. 먼저 시험해 보고, 결과를 보고 정규로 편성할지 정합니다.

## 1. 한 줄 요약

값싼 **축소 티칭 팔**(관절마다 가변저항)을 손으로 움직이면, **아두이노**가 각도를 읽어 우리 프로그램으로 보냅니다.
화면의 3D 팔(그다음 실물 myCobot 280)이 그대로 따라 하고, 그 동작을 기록해 **다시 재생하고 학습**합니다.
280을 두 대 쓰지 않고, 리더 팔 한 대에 대략 3~5만 원(추정)입니다.

## 2. 구성

| 부분 | 내용 |
| --- | --- |
| 티칭 팔 (리더) | 280과 관절 배치가 같은 축소판(3D 프린트). 관절 6개 + 그리퍼 손잡이 = 가변저항 7개. 크기는 손에 맞게 줄여도 됨(관절 각도만 맞으면 됨) |
| 센서 | 10 kΩ 선형 가변저항(돌아가는 범위 약 270°). 280 관절 범위(J1 ±168°, J6 ±180° 등)보다 좁으므로 티칭 팔은 **±135°** 안에서만 씀. 수업 동작은 대부분 이 안에 들어옴 |
| 보드 | **아두이노 나노(호환)** 추천: 아날로그 입력 8개(7개 사용), 5 V 기준이라 읽기가 고르게 나옴. ESP32 는 무선이 되지만 아날로그 값이 양 끝에서 휘어 보정이 더 필요함(2차 후보) |
| 연결 | USB 케이블 하나. 아두이노가 1초에 50번 `J,a0,…,a6` 한 줄씩 보냄(115200 bps). 브라우저 **Web Serial** 로 바로 받음(설치 없음, 크롬 · 엣지) |
| 프로그램 | 받은 값 → 잡음 거르기(평균 + 작은 떨림 무시) → 관절별 보정(0° · 90° 두 점) → 관절 한계 · 속도 제한 → **3D 팔이 따라 함** → 허락하면 **실물 280** 이 따라 함(로봇 서버 경유, 1초 10번 정도) |
| 기록 | 시연 한 번 = 시간 · 리더 각도 · 팔 각도 · 그리퍼(+ 선택: 카메라 사진). 파일로 저장(자료실 · 파일 열기와 같은 방식) |
| 학습 | 기초: **기록 재생**. 다음: 블록 위치를 바꿔 가며 시연 여러 번 → 블록 위치에 맞는 집는 자세를 **브라우저 안에서 학습**(가까운 시연 고르기 · 선형 회귀). 심화(선택): PC GPU 로 ACT 같은 모방학습 모델 |

정밀도 추정: 10비트 읽기 × 270° = 한 칸 약 0.26°. 잡음을 거르면 떨림 1° 안쪽이 목표(시험 T1 에서 확인).

## 3. 시험 순서와 통과 기준

| 시험 | 하는 일 | 통과 기준 |
| --- | --- | --- |
| T1 책상 위 | 가변저항 7개 + 나노, 값 읽기 | 50번/초, 거른 뒤 떨림 1° 안 |
| T2 보정 | 0° · ±90° 표시에 맞춰 놓고 읽기 | 오차 3° 안 |
| T3 시뮬레이터 따라 하기 | 리더 → 화면 3D 팔 | 눈으로 느끼는 지연 0.1초 안, 끊김 없음 |
| T4 실물 따라 하기 | 리더 → 280 | 지연 0.3초 안, 튀는 움직임 없음, 정지 버튼 · Esc 즉시 멈춤 |
| T5 기록 | 학생이 집어 옮기기 시연 | 15분에 20번 기록 |
| T6 재생 · 학습 | 시뮬레이터에서 | 재생 성공 90% 이상, 처음 보는 블록 위치에서 학습 결과 성공 70% 이상 |
| T7 시범 수업 | 한 조에 티칭 팔 한 대 | 준비 10분 안, 학생 설문 |

결정 시점: **T1~T4 뒤** 티칭 팔을 여러 대 만들지 결정 → **T7 뒤** 정규 편성 여부 결정.

## 4. 수업안 초안 (시험용 8차시)

| 차시 | 주제 | 활동 |
| --- | --- | --- |
| 1 | 사람이 가르치는 로봇 | 모방학습이 쓰이는 곳, 리더-팔로워 원리 |
| 2 | 티칭 팔 만들기 | 가변저항 배선, 아두이노 값 읽기(시리얼 모니터) |
| 3 | 보정 | 0° · 90° 두 점 보정, 방향(+/−) 맞추기 |
| 4 | 시뮬레이터 원격 조종 | 3D 팔이 따라 하기, 관절 한계 · 충돌 막힘 보기 |
| 5 | 실물 원격 조종 | 280 이 따라 하기, 안전 규칙 |
| 6 | 시연 기록 · 재생 | 집어 옮기기 시연 10~20번, 재생해 보기 |
| 7 | 학습 | 블록 위치를 바꾼 시연으로 학습, 새 위치에서 시험 |
| 8 | 평가 | 성공률 재기, 잘 된 시연 · 안 된 시연 비교 |

## 5. 프로그램에서의 자리

- 시험 동안은 왼쪽 메뉴에 **[티칭]** 하나를 "시험 기능"으로만 보이게 둡니다(설정에서 켤 때만).
- 화면: 연결(Web Serial) · 보정 · 따라 하기(시뮬레이터 / 실물) · 기록 · 재생 · 학습. 다른 화면처럼 버튼과 값만.
- 하드웨어 없이도 만들 수 있게 **가짜 티칭 팔 신호**(파일 재생)를 함께 둡니다. 화면 · 기록 · 학습은 먼저 만들고, 실물 티칭 팔이 오면 T1 부터 시험합니다.

## 6. 준비물 (리더 한 대, 대략 · 구매처 확인 전)

| 품목 | 수량 | 대략 |
| --- | --- | --- |
| 아두이노 나노 호환 + USB 케이블 | 1 | 1만 원 안 |
| 10 kΩ 선형 가변저항(축 6 mm) | 7(+여분) | 1만 원 안 |
| 3D 프린트 부품(PLA) | 한 벌 | 1만 원 안 |
| 나사 · 베어링 · 전선 | 한 벌 | 1~2만 원 |

## 7. 걱정되는 점

- **가변저항 수명 · 잡음**: 오래 쓰면 값이 튐 → 거르기와 교체 쉬운 구조. 문제가 크면 자석 엔코더로 바꿀 수 있게 아두이노 쪽 출력 형식은 같게 둠.
- **범위**: ±135° 밖 동작은 티칭 팔로 못 가르침(J1 · J6 끝 쪽). 수업 과제를 그 안으로 잡음.
- **실물 280 이 따라오는 속도**: 펌웨어가 명령을 받는 속도 때문에 빠르게 움직이면 늦게 따라옴 → T4 에서 재고, 필요하면 "느리게 가르치기" 규칙.
- **안전**: 실물 따라 하기는 선생님 허락 · 속도 상한 · 작업 범위 제한 · 정지 버튼을 기존 규칙 그대로.
