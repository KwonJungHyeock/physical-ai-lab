# 보고 #17 — 교육 탭을 로봇공학 로드맵(8개 학문)으로

로드맵 v3(8개 학문, 상품 M·K·P)을 교육 탭의 **대표 커리큘럼**으로 삼고, 콘텐츠 담당자의 학문 1 샘플(md)
형식을 그대로 원고 형식으로 정했습니다. 학문 2~8 은 같은 형식으로 초안을 썼고, 앱은 이 md 파일을 직접 읽습니다.

## 1. 구조

```
교육 탭 ─ 로드맵 (첫 화면)
          ├ 계단 8개: 1 기초 로봇공학 → … → 8 로봇 학습   (상품 M 역학 1~4 · K 제어 5 · P 계획·인식·학습 6~8)
          ├ 확장 학문(회색 5개): 센서·액추에이터, 로봇 소프트웨어, 이동 로봇·SLAM, 상태 추정, HRI·안전
          ├ 보유 제품 고르기 → 카드·추천·코스가 바뀜
          ├ 다음 학습 추천 (선수 학문을 마친 첫 학문의 다음 주제)
          └ 제품별 지도 (학문 × 제품, 초안)
        ─ 주제 화면 (기존 틀 그대로: 알아보기 → 자세히 → 실습 A·B·C → 비교 → 확인 문제 → 수식)
```

## 2. 원고 → 앱

- 원고: `content-markdown/N-학문명.md` (형식·작업 순서는 `content-markdown/README.md`).
- `web-typescript/tools/build/curriculum-md.mjs` 가 줄 모양대로 읽고(틀리면 파일·줄 번호로 멈춤), `npm run gen:curriculum` 이
  `web-typescript/src/engine/education/curriculum.gen.ts` 를 만듭니다. `npm run check:learn` 이 생성본이 원고와 같은지, 문항 수·수준 순서·정답
  균형, 용어가 사전에 있는지 검사합니다.
- 용어: 원고의 `새 용어` 가 사전에 더해지고, 같은 뜻의 다른 표기(공구 중심점(TCP)/도구 끝점, 회전행렬/회전 행렬)는 자동으로 맞춥니다.
  글 속 용어는 앱이 자동으로 밑줄(말풍선)을 답니다.
- 그림: 그림 제작 요청서 규격(1600×900, 색 4 + 회색, 글자 28px 이상, 라벨·숫자만)으로 28점을 코드(SVG)로 그렸습니다 — §6.
- 확인 문제: OX 3 + 객관식 2, 고등은 기본·응용만, 대학은 대학 문항까지.
