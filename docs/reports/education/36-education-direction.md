## 1. 정한 것

- **자료는 모두 자료실에.** 이론서 · 문항지 · 매뉴얼 · 실습 자료는 프로그램의 [자료실] 한 곳에 둡니다.
  다른 화면(시뮬레이터 · 교육 탭)은 자료를 펼쳐 보이지 않고, "자료실 ○○ 를 보세요" 처럼 안내만 합니다.
  시뮬레이터는 설명서가 아니라 프로그램이라는 원칙(보고 #34)과 같습니다.
- **교육 자료는 두 층.**
  - 이론 PDF: 로봇공학 이론의 상세 내용(지금의 이론서 8권 · 용어집 · 문항지). 읽을거리.
  - 실습 매뉴얼: 실제 수업 자료. 실습 순서대로, 실습하다 필요한 원리와 정보만 짧게 알려 주고 이론서 쪽 번호로 이어 줍니다.
- **개편 시점.** 납품(11월 초) 뒤, 제대로 된 커리큘럼이 나온 다음 시작합니다. 그때까지 지금 화면 · 자료는 그대로 둡니다.
- **지금 할 일.** 로봇공학 이론(이론서의 원고 `content-markdown/`)이 맞는지 검토하고 보완합니다(1 · 2단원은 보고 #32 후속에서 끝남, 3 ~ 8단원 진행).

## 2. 참고한 자료

PinkLAB 「모방학습: MuJoCo부터 실물 로봇까지」(2026-10-21 교육, 13개 모듈, 같은 원고로 PDF · 발표 화면 두 벌).

- 13개 모듈이 한 줄로 이어짐: 설치 → 장면 · 모델 → 리더 연결 → 텔레옵 → 녹화 → 학습 → 실습 1 · 2 → 실물 → 정리.
- 모듈마다 같은 틀: ① 무엇인가(그림 한 장 + 두 줄) → ② 실행(명령 → 실제 화면에 번호 설명 → 결과 읽기 → 막히는 곳 → 대처) → ③ 코드 발췌 → 해 볼 것 3개(숫자로 끝 확인, 예: Success 5/5).
- 이론은 실습 결과의 비교로 나옴(실습 1 시연 5회 · 고정 vs 실습 2 시연 50회 · 무작위 → 일반화).
- 화면 그림은 사람 대신 가짜 리더로 재현해 찍음(우리 가짜 로봇 + 자동 캡처와 같은 방식).
