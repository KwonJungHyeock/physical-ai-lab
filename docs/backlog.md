새 요청은 맨 아래에 붙입니다. 끝난 항목은 ~~줄을 긋고~~ 커밋 번호를 적습니다.

## 1. 연결 방식: Wi-Fi 유지 + LAN · 시리얼 (작은 것부터, 끝내 태블릿까지)

배경: 교육 현장에서는 LAN 포트 연결이나 시리얼 통신을 쓰고, 태블릿도 Wi-Fi 보다 시리얼을 씀.

1. **LAN 직결 모드**: 연결 창에 [유선(LAN) 직결] (주소 `192.168.127.10:8080` 미리 채움),
   PC · 태블릿 고정 IP(192.168.127.x) 설정 매뉴얼. 공유기 경유 유선은 이미 됨 (서버가 0.0.0.0:8080). 실물 1회 확인.
2. **USB 케이블 연결**: 로봇 보드 USB-C 를 "USB 네트워크"로 쓸 수 있는지 실물 확인 →
   되면 PC · 태블릿(갤럭시 탭)이 지금 웹 화면 그대로 케이블 한 줄로 연결.
3. **진짜 시리얼**: PC 는 브라우저 시리얼 (코드 `web-typescript/src/engine/serial/` 은 280 AR 용, 화면 미연결).
   280 RDK X5 에서 팔 명령을 받는 단자 실물 확인 필요 (팔 제어기는 보드 안쪽 `/dev/ttyS1`).
   태블릿은 웹으로 불가(안드로이드 크롬 USB 시리얼 없음, 아이패드 USB 막힘) → 지금 화면을 감싼 안드로이드 앱 + USB 시리얼.

## 2. 앞선 작업에서 남은 것

- 카드 모드(AIDT)를 바이오 ②③ · 다른 현장으로 넓히기 (바이오 ① 시범 완료: `2a38ea3` · `c208ca6`).
- 비교 카드 표의 "처음" 칸 실패 문장이 길어 세 줄로 꺾임 → 표에서는 짧게 (예: "쏟아짐 (31.1°)").
- `release` 브랜치 테스트 파일(시뮬레이터 zip · USB 키트) 다시 만들기 — 카드 모드 · 태블릿 대응 반영.
