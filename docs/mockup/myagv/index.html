하드웨어에 있는 것 · 이번 범위

✅ 이번에 만들기

  • 조종: 화면 조이스틱(이동) + 돌기, 키보드, USB·블루투스 게임패드. 손을 떼면 멈춤
  • 직진 보정: 1m 직진 테스트 → 휜 정도 재기 → 보정 저장, 자이로 방향 유지
  • 카메라: 앞 카메라, 사진, 색 카드 · ArUco 마커 찾기(거리 · 방향)
  • 라이다 보기: 주변 거리 점, 앞 장애물 거리 (블록 "앞 거리")

⏭ 하드웨어엔 있고, 다음 단계

  • 라이다: YDLIDAR X2L (360° · 0.12~8m), Plus 도 360° 라이다
  • SLAM 지도 만들기: Gmapping (Jetson Nano 는 Cartographer · RTAB-Map 도)
  • 자율 주행: move_base / Nav2 — 지도 위 목적지로
  • 280 을 얹은 복합 로봇, 게임패드 + 270 팔 예제

🔎 직진 보정에 대해 확인한 것

  • 공식 펌웨어 · API(pymycobot MyAgv)에는 모터를 하나씩 조정하는 명령이 없음 — 로봇은 앞뒤 · 옆 · 회전 3값만 받고 바퀴 배분은 바닥 보드가 함
  • 있는 것: 자이로 보정 상태(set_gyro_state), 멈춤 복구(restore), 모터 전체 전류
  • 그래서 3값에 더하는 보정값 + 자이로 방향 유지로 같은 효과를 냄 (로봇마다 저장)

교실 Wi-Fi 연결 — 가장 간편한 방식

추천: 교실 전용 공유기 하나

  1. 교사, 한 번: 공유기 이름을 EDUINO-LAB 으로, 로봇마다 주소 예약(.101~.130), 로봇에 번호 스티커
  2. 로봇마다, 한 번: 로봇의 공장 핫스팟에 붙어 콘솔의 [교실 Wi-Fi 연결]에서 이름 · 비밀번호 입력 → 로봇이 공유기로 옮겨 감 (다음부터 자동)
  3. 학생, 매 수업: PC 를 EDUINO-LAB 에 연결 → 바탕화면 바로가기 → [로봇 찾기] → 목록에서 내 로봇 → 불빛이 깜빡이면 맞음

대안 1: 로봇 핫스팟 (공유기 없을 때)

  • PC 가 로봇의 Wi-Fi(ElephantRobotics_AP_…)에 직접 연결, 주소는 늘 10.42.0.1
  • 1:1 은 간단하지만 그동안 PC 인터넷이 끊기고, 교실에 핫스팟이 많으면 서로 방해

대안 2: 학교 Wi-Fi

  • 기기끼리 통신을 막아 두는 경우가 많음(클라이언트 격리 · 포트 차단) → 연결이 안 될 수 있음
  • 쓰려면 학교 전산 담당에게 허용 요청 필요

앱에 들어갈 것

  • [교실 Wi-Fi 연결] 설정 화면 (로봇 핫스팟으로 처음 한 번)
  • [로봇 찾기]: 같은 Wi-Fi 의 로봇을 자동으로 목록에, 누르면 불빛 · 동작으로 확인
  • 280 RDK X5 도 같은 방식 (같은 서버 · 같은 화면)

들어갈 기능

조종

  • 화면 조이스틱: 끄는 방향 · 거리 = 이동 방향 · 속도 (메카넘이라 대각선 · 옆도)
  • 돌기: 좌우로 끄는 막대, ■ 멈춤
  • 키보드 W A S D Q E, Space 멈춤
  • 게임패드: 왼쪽 스틱 이동, 오른쪽 스틱 돌기 (브라우저 기본 기능, 설치 없음)
  • 최고 속도 제한 0.05~0.5 m/s, 부드러운 가감속, 유지 신호 끊기면 로봇이 스스로 정지

직진 보정

  • 보정 줄(1m 테이프)에서 1m 직진 테스트
  • 자이로로 방향 틀어짐, 줄자 · 카메라로 옆 밀림 재기
  • 보정 저장: 로봇마다 회전 · 옆 보정값 (로봇 안에 저장)
  • 방향 유지: 직진 중 자이로로 계속 바로잡기
  • 시뮬레이터는 모터 하나를 약하게(뒤 오른쪽 88%) 만들어 보정 전 · 후 궤적을 비교
