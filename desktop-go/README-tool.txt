Physical AI 로봇 설치 도구
=========================

로봇을 교실 Wi-Fi 에 붙이고, 처음 쓰는 로봇에 프로그램을 설치하는 PC 프로그램입니다.
시뮬레이터와 수업은 웹에서 엽니다: https://physical-ai-lab-lake.vercel.app/console

1. 받은 PhysicalAI-RobotTool.zip 을 오른쪽 클릭 → [압축 풀기].
   폴더 안의 eduino_usb.zip(로봇 키트)은 풀지 말고 그대로 두세요. 프로그램이 옆에서 찾아 씁니다.
2. "로봇 설치 도구.exe" 를 더블클릭합니다. "Windows 의 PC 보호" 창이 뜨면 [추가 정보] → [실행].
3. 엣지(또는 크롬) 창에서 둘 중 하나를 고릅니다.
   - 로봇 USB 만들기: Wi-Fi 이름 · 비밀번호를 적은 USB 를 만들어 로봇에 꽂습니다.
     로봇 프로그램도 최신으로 바뀌고, 로봇이 결과를 USB 에 적어 줍니다.
   - 새 로봇 설치: 처음 쓰는 로봇. PC 랜 포트와 로봇 LAN 포트를 랜선 하나로 바로 잇고 [설치 시작].
     "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 [예] (설치하는 동안만 PC 랜 포트 주소를 바꿉니다).
4. 끝낼 때는 창과 함께 뒤에 있는 검은 창을 닫습니다.
