ROBODYNE SYSTEMS · Physical AI 로봇 학습 프로그램 — 시뮬레이터
==================================================

PC 에서 바로 여는 프로그램입니다. 설치·인터넷이 필요 없고, 같은 Wi-Fi 의 로봇을 찾아 바로 연결합니다.
그림으로 된 사용법: 「시뮬레이터 사용 매뉴얼.pdf」, 수업 운영: 「교사용 교육 가이드라인.pdf」

1. 이 폴더를 바탕화면 등 아무 곳에 압축을 풀어 둡니다.
2. "Physical AI 시뮬레이터.exe" 를 더블클릭합니다.
   - 처음 실행할 때 파란 창 "Windows의 PC 보호" 가 나오면
     [추가 정보] → [실행] 을 누릅니다. (회사 인증서 서명이 없는 프로그램이라 나오는 안내입니다)
3. 엣지(또는 크롬) 창으로 시뮬레이터가 열립니다. 시작 화면이 끝나면 [연결하기] 를 누릅니다.
   [로봇 연결] 창이 이 PC 의 Wi-Fi 에서 로봇을 저절로 찾아 사용자 이름 · IP · 로봇 ID 로 보여 줍니다.
   - 내 로봇의 [연결] → 그 로봇으로 바로 실습. 로봇 없이 하려면 [시뮬레이션만 (로봇 없이)]
     (또는 시작 화면의 [시뮬레이터로 시작] → 로봇 모델 myCobot 280 RDK X5 [시작]).
   - 로봇 쪽 준비: USB 의 eduino/wifi.txt 에 와이파이·비밀번호·사용자 이름을 적어 로봇에 꽂기.
   - 위쪽 탭: 교육(첫 화면: 이어서 수업하기 · 학습 로드맵 · 대단원별 단원 · 장비 선택하기 → 단원 미리보기 → 수업 화면) · 시뮬레이터 · 라이브러리 · 자료실
   - 라이브러리: 실습 과제 · 검수 7종 시연 · 실습 환경 · 로봇 모델 · 도구를 움직이는 그림 카드로 골라 바로 열기
   - 자료실: 폴더 창처럼 — PC 프로그램 · 교재와 문항지 PDF · 그림과 시연 GIF · 매뉴얼 PDF · 검수 결과표 (인터넷 없이 받기)
   - 시뮬레이터 오른쪽 탭: 수동 제어(조그) · 블록 코딩 · Python · ROS 2
   - 3D 화면 아래 [실습 환경] 막대: 빈 화면 · 실험실 · 제조 라인 · 물류 · 생활 장면, 매트 · 물리, 물건 놓기
   - 프로그램을 돌린 뒤에는 같은 자리에 실행 막대가 나와, 끌거나 재생해서 어느 순간이든 다시 볼 수 있음
   - 도구 칸에서 카메라 플랜지를 켜면 손 카메라 · 색 따라가기
4. 끝낼 때는 시뮬레이터 창과 함께 뒤에 있는 검은 창을 닫습니다.

- 엣지나 크롬이 필요합니다 (윈도우 10/11 에는 엣지가 기본으로 있습니다).
- 저장한 자세·진행 상황은 이 PC 에 남아, 다음에 열어도 그대로입니다.
- 나중에 연결하려면 오른쪽 위 [로봇 연결] → [로봇 찾기] (같은 Wi-Fi 일 때).
