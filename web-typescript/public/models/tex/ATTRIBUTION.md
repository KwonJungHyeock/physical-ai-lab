# Site floor and wall textures — CC0

Each folder holds one Poly Haven texture set (colour, OpenGL normal, roughness), resized and saved as
WebP by `web-typescript/tools/build/tex-pack.mjs` (sets marked grey lose their colour; the scene tints
them). No credit is required by the licence; it is given here with thanks.
