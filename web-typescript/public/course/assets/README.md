# 입문 과정 에셋 슬롯

장별 가이드라인 v1의 비주얼(손 · 사진 · 구성품 그림 등)은 코드로 그리지 않고 이 폴더의 그림으로 채운다.
파일이 없으면 화면에 '에셋 슬롯 · 이름 · 파일 준비 중' 자리만 보인다. 파일 이름(확장자 .png)이 슬롯 이름이다.
손은 1-1과 5장(글씨 부스 절 전체)이 같은 그림을 함께 쓴다(무대 콘셉트 지시서 v1). 배경이 투명한 PNG로 받는다.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| `hand.png` | 1-1, 4-3, 5-1 ~ 5-3 | 사람 손 · 다가오기 자세 (손님 쪽, 화면 아래에서 들어와 카드 앞에서 멈춤 · 다 쓴 카드를 가져갈 때도) |
| `hand-card.png` | 4-3, 5-1 ~ 5-3 | 사람 손 · 카드 놓기 자세 (카드를 쥐고 매트에 내려놓는 손) |
| `test1-photo1.png` ~ `test1-photo6.png` | 1장 수행평가 | 로봇 사진 6장 (협동로봇 3 · 아닌 것 3), 팀에서 정해 전달 |
| `part-robot.png` · `part-mat.png` · `part-pen.png` · `part-card.png` · `part-cable.png` | 2-1 | 구성품 상자 속 구성품 5개 그림 (로봇 · 매트 · 펜 · 카드 · 케이블, 실물 키트 사진이나 그림) |
