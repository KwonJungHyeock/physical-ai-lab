# 입문 과정 에셋 슬롯

장별 가이드라인 v1의 비주얼(손 · 작업 범위 원 · 사진 · 구성품 그림 등)은 코드로 그리지 않고 이 폴더의 그림으로 채운다.
파일이 없으면 화면에 '에셋 슬롯 · 이름 · 파일 준비 중' 자리만 보인다. 파일 이름(확장자 .png)이 슬롯 이름이다.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| `hand.png` | 1-1 | 로봇 쪽으로 다가오는 사람 손 |
| `range-280.png` | 1-3 | 로봇 베이스 둘레 작업 범위 원 (반지름 280 mm) |
| `test1-photo1.png` ~ `test1-photo6.png` | 1장 수행평가 | 로봇 사진 6장 (협동로봇 3 · 아닌 것 3), 팀에서 정해 전달 |
